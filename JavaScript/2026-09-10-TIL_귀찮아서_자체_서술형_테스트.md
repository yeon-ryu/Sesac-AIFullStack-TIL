### 배열 고차 함수
#### forEach
배열.forEach(current => {})  
배열의 각 요소를 돈다.  
forEach 자체는 콜백의 리턴을 반환하지 않고 undefined 를 반환한다.

&nbsp;

#### map
배열.map(current => 새로운값을만들고싶은요소 리턴)  
배열의 각 요소를 돌며 반환된 콜백 값으로 새로운 배열을 만든다.  

&nbsp;

#### filter
배열.filter(current => 조건식)  
배열에서 조건에 맞는 요소들만으로 새로운 배열을 만든다.  

&nbsp;

#### find
배열.find(current => 조건식)  
배열에서 조건에 맞는 제일 첫 요소를 찾는다. 요소를 찾으면 검색을 종료한다.  
조건에 맞는 요소를 찾지 못하면 undefined 를 반환한다.  

&nbsp;

#### some
배열.some(current => 조건식)  
배열 전체에서 조건에 어느 하나라도 일치하는지 확인한다.  
하나라도 조건이 맞으면 true 를 반환하고 끝낸다. OR 연산자와 비슷하다.

&nbsp;

#### every
배열.every(current => 조건식)  
배열 전체가 조건에 맞는지 확인한다.  
하나라도 조건이 틀리면 false 를 반환하고 끝낸다. AND 연산자와 비슷하다.

&nbsp;

#### sort
배열.sort((a, b) => { return a와 b를 비교한 값; })  
콜백 함수의 return 값이 음수면 a 를 앞에 정렬하고, 양수면 a 를 뒤에 정렬한다.  
배열을 정렬한다. 배열을 바꾼다. 기본적으로는 값을 문자열로 바꾸어 오름차순으로 정렬한다.

&nbsp;

#### reduce
배열.reduce((sum, current) => sum + current, 초기값) 형식으로 합계를 구한다.  
reduce 는 콜백 함수의 리턴 값이 다음 sum 안에 들어간다.  
빈 배열의 경우 초기값을 반환하고, 초기값이 없으면 에러 발생.  
빈 배열이 아닐 경우 초기값이 없을 때, 시작할 때 첫번째 요소를 sum 에 넣고 두번째 요소를 current 에 넣는다.
