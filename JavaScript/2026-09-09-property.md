# JavaScript
## 모던 연산자
### 옵셔널 체이닝 연산자
ES11 부터 도입됨.  
좌항의 피연산자가 null 또는 undefined 인 경우 undefined 를 반환하고 그렇지 않으면 우항의 프로퍼티 참조를 이어간다.  
객체 속성을 안전하게 읽고 싶을 때 사용한다.
```javascript
// 옵셔널 체이닝 연산자 (?.)
const obj = null;
let val = obj?.value; // undefined
// let val = obj.value; // TypeError 에러 발생
```
옵셔널 체이닝 이전엔 논리 연산자(&&)를 사용한 단축 평가로 확인을 했다.  
단, 빈 문자열과 같은 Falsy한 값을 false 취급해서 생기는 문제가 있다.
```javascript
const str = '';
// const len = str && str.length; // 원하는 값 : 0, 실제 값 : ''
const len = str?.length; // 0
```

### null 병합 연산자
좌항의 피연산자가 null 또는 undefined 인 경우 우항의 피연산자를 반환하고, 그렇지 않으면 좌항의 피연산자를 반환한다.  
기본 값을 설정할 때 사용하는 연산자  
null 병합 연산자 이전엔 논리 연산자(||)를 사용한 단축 평가로 확인을 했다.  
단, 빈 문자열과 같은 Falsy한 값을 false 취급해서 생기는 문제가 있다.
```javascript
// null 병합 연산자 (??)
const test = null ?? '기본 값'; // 기본 값

// const value = '' || '기본 값'; // 원하는 값 : '', 실제 값 : '기본 값'
const value = '' ?? '기본 값'; // ''
```

## 생성자 함수
```javascript
/**
 * const this = {}; 라는 빈 객체를 만들고
 * 프로퍼티를 할당한 후
 * 완성된 this 객체를 호출 결과(return)로 반환하는 방식
 */
function Student(name, age) { // 대문자로 시작하는 함수는 객체 생성 함수인게 관례
    // 객체에서 this 는 자기 자신을 가리키기에 생성될 객체를 의미함
    this.name = name;
    this.age = age;
    this.getInfo = function() {
        return `${this.name}는 ${this.age}세 입니다.`;
    }
    // return this; // 자동으로 동작되어 생략되어 있다.
}

const student1 = new Student('나무늘보', 10); // 나무늘보는 10세 입니다.
```

### 인스턴스 생성 프로세스
```javascript
'use strict'; // 엄격 모드
```
```javascript
function Student(name, age) {
    console.log(`this가 있는가 :`, this !== undefined); // true
    console.log(`name이 있는가 :`, 'name' in this); // in 연산자 : this 안 프로퍼티 여부 체크 // false
    this.name = name;
    this.age = age;
    this.getInfo = function() {
        return `${this.name}는 ${this.age}세 입니다.`;
    }
    console.log(`초기화된 값 :`, this.name, this.age);
}

const student = new Student('호랑이', 50); // new 를 제거하면 this 객체가 없기에 에러가 발생한다.
console.log(`객체를 반환받았는가 :`, typeof student === 'object'); // true
```
생성자 생성 시 new 를 안 붙었을 때를 대비하여 방어 코드 작성  
new.target : new Dog 를 호출하면 Dog 를 가리키고 일반 호출하면 undefined 가 들어간다.
```javascript
function Dog(name, age) {
    // 방어 코드
    if(!new.target) {
        console.log(`new 가 없습니다. new 를 붙여 다시 실행합니다.`);
        return new Dog(name, age);
    }
    this.name = name;
    this.age = age;
}

const dog = Dog('바둑이', 3);
```

### 프로토타입
프로토타입 : 상속에서 부모에 해당하는 객체  
    나한테 없는 프로퍼티를 찾아볼 수 있는 객체
```javascript
const user = {
    id : 'user',
    activate : true,
    login : function() {
        console.log(`${this.id} is sign in.`);
    }
};

/**
* Object.create : 새로운 빈 객체를 만들고 그 객체가 프로퍼티를 찾을 때 user도 살펴볼 수 있도록 연결한다.
* student 의 프로토타입을 user 로 설정 (student 가 user 를 상속 받음)
*/
const student = Object.create(user);

// Object.getPrototypeOf : 프로토타입으로 연결한 객체 정보 확인
console.log(Object.getPrototypeOf(student)); // { id: 'user', activate: true, login: [Function: login] }

// Object.hasOwn : 객체가 특정 프로퍼티를 직접 가지고 있는가
console.log(`자신의 activate :`, Object.hasOwn(student, 'activate')); // false
console.log(`자신의 passion :`, Object.hasOwn(student, 'passion')); // true

// in 연산자 : 그 객체에서 해당 프로퍼티에 접근이 가능한가
console.log('activate' in student); // true
```
- **Object.create(부모객체)** : 부모 객체의 자식 객체를 생성
- **Object.getPrototypeOf(자식객체)** : 자식 객체의 부모 객체 정보 확인
- **Object.hasOwn(객체명, ‘프로퍼티명’)** : 해당 객체가 해당 프로퍼티를 직접 가지고 있는가
- **‘프로퍼티명’ in 객체명** : 해당 객체에서 해당 프로퍼티에 접근 가능한가

&nbsp;

**프로토타입 체인** : 자신한테 없는 프로퍼티를 부모로 올라가며 찾는다. (부모-자식-자식의 자식.. 형태 상속)  
※ 읽는 것은 프로토타입을 통해 가능하지만 수정/삭제는 프로토타입을 통해할 수 없다.
```javascript
// 부모의 login 프로퍼티까지 찾아갔지만 login 에서 가리키는 this 는 호출한 주체인 greedyStudent
greedyStudent.login();

// greedyStudent 에 id 프로퍼티가 추가된다.
greedyStudent.id = 'student01'

// delete 로 제거되는건 본인이 직접 가지고 있는 프로퍼티만 가능
delete greedyStudent.id;
console.log(greedyStudent.id); // user
```

### 생성자 프로퍼티
javascript 는 생성자를 만들면 자동으로 prototype 이라는 프로퍼티(객체)를 할당해준다.  
생성자를 통해 만들면 this 는 (생성자 함수명)Student.prototype 의 자식으로 연결된다.  
Student.prototype 으로 불러서 공유되는 **부모 객체 프로퍼티로 적용**할 수 있다. → 정보가 다르더라도 공통적으로 사용하는 기능을 prototype 에 만들어서 사용하면 **딱 하나만 생성되어 자원을 아낄 수 있다.**
```javascript
function Student(name, age) {
    this.name = name;
    this.age = age;
}

/**
 * 생성자를 통해 만들면 this 는 Student.prototype 에 연결된다.
 * Student.prototype : javascript 가 prototype 이라는 프로퍼티(값은 객체)를 기본적으로 마련해줌.
 * student1 의 프로토타입이 Student.prototype 이 된다.
 */ 
const student1 = new Student('panda', 8);
const student2 = new Student('daranji', 5);

// Student 의 프로퍼티에 activate 라는 프로퍼티를 추가하였다.
Student.prototype.activate = true;
Student.prototype.getInfo = function() {
    return `${this.name} is ${this.age} years old.`; 
};

console.log(student1.activate);
console.log(student2.getInfo());

console.log(student3.getInfo === student4.getInfo); // true : 객체 자체가 같은 객체 인가
console.log(student3.getInfo() === student4.getInfo()); // false : 객체를 실행한 결과가 같은 값인가
```

### [[Prototype]]
[[Prototype]] : 프로토타입이 어디랑 연결되어 있는지 등 내부 구조 정보가 저장되어 있는 숨김 프로퍼티  
[[Prototype]] ≠ Student.prototype
```javascript
// 개발자 도구 Console 에서 확인 가능
const parent = { hello : '안녕' };
const child = Object.create(parent);
child.name = '판다';
console.log(child); // 내부구조 확인 가능
/*
{name: "판다",
	[[Prototype]]: {
		hello: "안녕",
		[[Prototype]]: Object
	}
}
*/
```
