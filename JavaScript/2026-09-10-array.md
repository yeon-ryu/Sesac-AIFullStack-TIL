# JavaScript
## 배열
### 배열의 기초
- array 배열 : 관련된 값들을 하나의 목록으로 묶어서 관리
- 배열 리터럴 방식 : 대괄호로 감싸고 콤마로 구분하는 방식
- 요소 : 배열 안에 들어 있는 값
```javascript
// 배열 리터럴
const fruits = ['banana', 'pitch', 'kiwi'];

// 배열의 요소 읽어오기 : 배열이름[index]
// 배열에서는 위치를 나타내는 번호(index)가 있다. 인덱스는 0부터 시작한다.
fruits[1];
console.log(fruits[3]); // undefined // 스택오버플로우가 아니네
console.log(fruits.length); // 3 // 배열도 객체이기에 length 라는 프로퍼티가 존재

// 배열도 객체이기에 배열 자체가 아닌 내부 요소의 재할당은 가능하다.
fruits[1] = 'strawberry';
console.log(fruits);

// 배열인지 확인
console.log(Array.isArray(fruits)); // true
```

#### 배열 메서드
```javascript
const food = ['짜장면', '짬뽕', '볶음밥'];

// push : 배열의 끝에 요소를 추가하고 새 길이를 반환
console.log(food.push('탕수육')); // 4

// pop : 배열의 끝의 요소를 제거하고 제거한 요소를 반환
console.log(food.pop()); // 탕수육

// unshift : 배열의 맨 앞에 요소 추가하고 변경 후 길이를 반환
food.unshift('유산슬'); // 4

// shift : 배열의 맨 앞 요소를 제거하고 제거한 요소를 반환 // 삭제 후 배열을 다 왼쪽으로 이동하는 느낌
food.shift(); // 유산슬


// 배열은 순서가 있고 중복도 존재할 수 있다.
const foodList = ['물회', '삼계탕', '냉명', '수박', '물회'];

// indexOf('값') : 값이 처음으로 나오는 인덱스 반환. 찾는 값이 존재하지 않을 경우 -1 반환
console.log(foodList.indexOf('물회')); // 0
console.log(foodList.indexOf('삼겹살')); // -1

// includes('값') : 값이 있으면 true, 없으면 false 반환
console.log(foodList.includes('냉면')); // true
console.log(foodList.includes('삼겹살')); // false
```

### 배열 고차 함수
#### forEach
배열 요소를 하나씩 전달 받아 사용
```javascript
const students = [
    {name : 'Hong gil dong', score : 90},
    {name : 'Gwon pan da', score : 80},
    {name : 'Yu guan sun', score : 95}
];


// 배열.forEach(콜백 함수) : 배열 요소를 하나씩 전달 받아 사용
students.forEach(s => {
    // 복사가 아니라 원본 객체 그대로 전달하기에 주의!
    console.log(s.name);
});

// forEach 에서 사용하는 함수는 기본적으로 매개변수 하나만 받는다.
// 하나 더 받으면 두번째 매개변수는 무조건 인덱스
// 세번째 매개변수는 원본 배열
students.forEach((s, index) => {
    console.log(index + 1, '번째 이름 :', s.name);
});
```

&nbsp;

#### map
각 요소를 콜백의 반환값으로 바꾼 결과를 새 배열로 만들어 준다.
```javascript
// 고차함수 forEach 가 반환하는 값은 undefined. 콜백 함수의 반환값을 모아주지 않는다.
const ignoreNames = students.forEach(s => s.name);
console.log(ignoreNames); // undefined

// 배열.map(콜백 함수) : 각 요소를 콜백의 반환값으로 바꾼 결과를 새 배열로 만들어 준다.
// 원본 배열에 영향을 주지는 않는다. (콜백 안에서 코드로 영향을 줄 수는 있다.)
const studentNames = students.map(s => s.name);
console.log(studentNames); // [ 'Hong gil dong', 'Gwon pan da', 'Yu guan sun' ]

// 점수에 5점을 더하여 배열로 반환받기
const adjustedScores = students.map(s => s.score + 5);
console.log(adjustedScores); // [ 95, 85, 100 ]
```

#### filter
콜백 함수의 반환 결과가 true 인 요소만 모아 새로운 배열을 만든다.
```javascript
const students = [
    {name : 'Hong gil dong', score : 90},
    {name : 'Gwon pan da', score : 80},
    {name : 'Yu guan sun', score : 95}
];

const highScorers = students.filter(student => student.score >= 85);

// 조건을 만족하지 못하면 빈 배열을 반환한다.
console.log(students.filter(student => student.score >= 100)); // []
```

&nbsp;

#### find
처음으로 조건을 통과한 요소 하나를 반환하고 검색을 끝낸다.
```javascript
const firstHighScorer = students.find(student => student.score >= 85);

// 조건을 만족하지 못하면 undefined 를 반환한다.
// find 로 맞는 요소를 찾지 못하면 undefined 를 반환하기 때문에 안정적인 접근을 위해 옵셔널 체이닝 연산자(?.)를 사용할 수 있다.
console.log(students.find(student => student.score >= 100)); // undefined
```

&nbsp;

#### some
배열 전체에서 조건에 맞는 요소가 한개라도 있는지 확인하고 불리언 값을 반환한다. (OR 연산자에 가까움)
```javascript
const hasHighScorer = students.some(student => student.score >= 85); // true
```

&nbsp;

#### every
배열의 모든 요소가 조건에 만족하는지 확인하고 불리언 값을 반환한다. (AND 연산자에 가까움)
```javascript
const allHighScorer = students.every(student => student.score >= 85); // false
```

#### sort
원본 배열을 변경하여 정렬한다.  
- 반환값 음수 : a를 b보다 앞에 놓는다.
- 반환값 양수 : a를 b보다 뒤에 놓는다.
- 0 : 이 비교 기준에서 같은 순위로 취급한다.
```javascript
const numbers = [3, 1, 9, 10, 5];

// sort() : 숫자 크기로 비교하는게 아니라 문자열로 바꿔서 비교함. 문자열은 앞쪽 문자부터 비교함.
// 원본 배열을 직접적으로 바꾼다.
const sorted = numbers.sort(); // [ 1, 10, 3, 5, 9 ]

console.log(sorted === numbers); // true;


// 오름차순
numbers.sort((a, b) => a - b); // [ 1, 3, 5, 9, 10 ]
// 내림차순
numbers.sort((a, b) => b - a); // [ 10, 9, 5, 3, 1 ]
```

#### reduce
반환값을 받아 다음 호출로 넘겨준다.  
배열.reduce(콜백 함수(누적값, 이번에 처리할 배열 요소), 초기값);  
누적값은 자동 합계가 아니라 콜백 함수로 리턴된 값만 합쳐진다.
```javascript
// reduce : 요소들의 합계
const amounts = [1000, 2000, 3000];

// 누적하기 - reduce 사용
// 배열.reduce(콜백 함수, 초기값);
const total = amounts.reduce((sum, current) => {
    return sum + current;
}, 0);


// 빈 배열의 경우 초기값 0 을 반환한다.
// 초기값이 없으면 에러 발생. 빈 배열이 아니면 첫 요소를 누적값으로 시작하고 두번째 요소부터 current 에 넣어준다.
[].reduce((sum, current) => sum + current, 0); // 0
```

## 표준 빌트인 객체
### String
문자열은 변경할 수 없는 값이므로 메서드를 실행해도 원본은 바뀌지 않고 처리한 결과를 반환 받아 사용한다.
1. trim : 문자열 앞뒤 공백 제거
    ```javascript
    const rawKeyword = '    JavaScript    ';
    console.log(rawKeyword); // '    JavaScript    '

    const trimmedKeyword = rawKeyword.trim();
    console.log(trimmedKeyword); // 'JavaScript'
    ```
2. toLowerCase, toUpperCase : 영문 대소문자 정리
    ```javascript
    const keyword = trimmedKeyword.toLowerCase();
    console.log(keyword); // javascript
    console.log(trimmedKeyword.toUpperCase()); // JAVASCRIPT
    ```
3. 문자열 검색
    - indexOf : 검색어가 시작하는 인덱스 반환, 찾지 못하면 -1 을 반환
    - includes : 검색어가 들어있는지를 true 또는 false 로 반환
    ```javascript
    const title = 'JavaScript 배열 수업';
    const searchTitle = title.toLowerCase();
    console.log(searchTitle.indexOf(keyword)); // 0
    console.log(searchTitle.indexOf("python")); // -1

    // includes : 검색어가 들어있는지를 true 또는 false 로 반환
    // 일부만 일치해도 true 반환
    console.log(searchTitle.includes(keyword)); // true
    console.log(searchTitle.includes("python")); // false
    ```
4. slice : 필요한 부분 가져오기
    substr 과 비슷한 동작
    ```javascript
    // slice(시작 인덱스, 끝 인덱스) 시작 인덱스는 포함하고 끝 인덱스는 포함하지 않는다.
    const fileName = "my-profile.jpg";
    console.log(fileName.slice(0, 10)); // my-profile

    // lastIndexOf('.') : 문자열에서 마지막 마침표(.)의 인덱스 반환
    const dotIndex = fileName.lastIndexOf('.');
    console.log(dotIndex); // 10
    // 끝 인덱스를 생략하면 문자열 끝까지 가져온다.
    const extension = fileName.slice(dotIndex);
    console.log(extension);
    ```
5. split : 문자열을 배열로 나누기
    ```javascript
    const tags = '#자바스크립트#개발자#프론트엔드';
    const tagParts = tags.split('#');
    console.log(tagParts); // [ '', '자바스크립트', '개발자', '프론트엔드' ]
    ```
6. 배열 메서드로 빈 값 제외
    ```javascript
    const tagList = tagParts.filter(tag => tag?.length > 0); // tag => tag !== ''
    console.log(tagList); // [ '자바스크립트', '개발자', '프론트엔드' ]
    ```
메서드 체이닝 방식
```javascript
const tagList2 = tags.split('#').filter(tag => tag?.length > 0); // [ '자바스크립트', '개발자', '프론트엔드' ]
```

### Math
1. 반올림 내림 올림
    - round : 소수점 이하 반올림
    - floor : 주어진 수보다 크지 않은 정수 중 가장 큰 값 반환 (내림)
    - ceil : 주어진 수보다 작지 않은 정수 중 가장 작은 값 반환 (올림)
    ```javascript
    console.log(Math.round(3.6)); // 4
    console.log(Math.floor(3.6)); // 3
    console.log(Math.ceil(3.6)); // 4
    ```
2. Math.random : 실행할 때마다 0 이상 1 미만의 임의의 실수를 반환
    ```javascript
    const randomValue = Math.random(); // 0.7395173194372374
    console.log(randomValue);

    const zeroToNine = Math.floor(randomValue * 10);
    console.log(zeroToNine);
    ```
3. 배열에서 무작위 요소 선택
    ```javascript
    const menus = ['비빔밥', '우동', '김밥'];
    const menuIndex = Math.floor(Math.random() * menus.length);
    console.log('선택 인덱스', menuIndex);
    console.log('추천 메뉴', menus[menuIndex]);
    ```

### Date
날짜와 시간을 표현하는 객체  
기본적으로는 UTC 시간으로 표시된다.
```javascript
// 생성 당시의 시점을 나타내는 Date 객체 생성
const now = new Date();
console.log(now); // 표준시간대이기에 UTC 시간으로 나온다.
```
1. 시간 표시 방식 변경
    ```javascript
    // 시간을 한국어로 표시 (별도 실행환경이 없으면 실행환경의 시간대로 변경된다.)
    now.toLocaleString('ko-KR'); // 2026. 9. 11. 오전 9:20:16

    // 항상 아시아-서울 시간대 기준으로 보여주게 설정
    now.toLocaleString('ko-KR', {timeZone : 'Asia/Seoul'}); // 2026. 9. 11. 오전 9:20:16
    ```
2. 필요한 요소 추출
```javascript
// 숫자로 반환됨
const year = now.getFullYear();
const month = now.getMonth() + 1; // 달 번호가 0부터 시작함
const date = now.getDate();

console.log(`${year}년 ${month}월 ${date}일`); // 2026년 9월 11일
```
