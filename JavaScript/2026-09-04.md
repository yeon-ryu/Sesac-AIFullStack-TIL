# JavaScript
## JavaScript 개요
### JavaScript 특징
JavaScript : 브라우저에서 동작하는 경량 프로그래밍 언어
- 웹 브라우저에서 동작하는 대표적인 프로그래밍 언어
- 동적 타입 언어
- 개발자가 별도의 컴파일 작업을 수행하지 않는 **인터프리터 언어** : 한 줄 씩 바로바로 실행 (컴파일 언어 랑 반대됨)
- 프로토타입 기반의 객체지향 언어

### JavaScript 역사
1. 크로스 브라우징 이슈를 해결하기 위해 javascript 를 표준화  
_크로스 브라우징 이슈 : 브라우저에 따라 웹 페이지가 정상적으로 동작하지 않는 현상_
2. ES5 (ECMAScript5) : HTML6 와 함께 출현한 표준 사양
3. ES6 : 현재의 표준 사양에 가까운 대개혁
4. Node.js(2009년) : 서버 사이드 애플리케이션에서도 사용할 수 있게 내장 API를 제공. JavaScript가 프론트엔드에서부터 백엔드까지 아우르는 웹 프로그래밍 언어의 표준으로 자리 잡았다.

## JavaScript 기본 문법
### 변수, 키워드
- 변수(variable) : 데이터를 저장할 때 쓰이는 이름이 붙은 저장소
- 변수 선언 방법 : 키워드 변수명;
- 키워드 : 변수를 어떤 규칙으로 만들지 정함
- 변수명 : 값을 다시 사용할 때 부를 변수 이름


| 키워드 | 특징 | 비고 |
| --- | --- | --- |
| var | 모든 변수 | ES5까지 사용했던 유일한 키워드 |
| let | 값을 변경할 수 있는 변수 선언 | 단점을 보안하기 위해 ES6 에서 새로 도입 |
| const | 재할당 금지 (불가) | 단점을 보안하기 위해 ES6 에서 새로 도입 |


**변수명 규칙**
- 변수명에는 문자, 숫자, _, $ 등을 사용할 수 있다. (다른 특수문자 사용 불가)
- 변수명은 숫자로 시작할 수 없다.
- 카멜 케이스 사용이 일반적이다.
- 이미 프레임워크에서 사용중인 예약어는 변수명으로 지정할 수 없다.

### Primitive Type (원시 타입)
동적 타입 언어(JS, Python 등)

- 변수에 현재 들어 있는 값에 따라 타입이 결정된다.

JavaScript 타입 종류

- number (숫자) : 하나의 숫자 타입만 존재하고 모든 수를 실수로 처리한다.
- string (문자열) : 작은 따옴표, 큰 따옴표, 또는 백틱(``)으로 텍스트를 감싼다.
- boolean (불린) : 논리적 참, 거짓을 나타내는 true 와 false 뿐이다.
- null : 값이 없음을 의도적으로 명시할 때 사용 (값은 null, typeof 는 object)
- undefined : 변수에 값이 할당되지 않았을 때 자동으로 할당되는 값 (값은 회색 undefined, 타입은 undefined)
```html
// 변수 타입
typeof 변수명
```

### 템플릿 리터럴
ES6 부터 도입된 문자열 표기법  
작은 따옴표, 큰 따옴표 대신 백틱을 사용해 표현한다.  
백틱으로 만든 템플릿 리터럴에서는 ${}안에 변수나 계산식을 넣을 수 있다.  
백틱 안에서는 일반 줄바꿈이 허용되고 공백이 있는 그대로 적용된다.
```html
// 템플릿 리터럴 사용(표현식 삽입)
console.log(`제 이름은 ${firstName} ${lastName} 입니다.\\n`);
```

### 암묵적 타입 변환
개발자가 직접 변환을 명령하지 않아도 자바스크립트 엔진이 문맥에 맞게 타입을 자동 변환하는 것

**문자 타입으로 변환**
```javascript
// + 는 문자열이 끼여들면 연결 연산자로 동작
// 다른 타입을 문자열 타입으로 암묵적 타입 변환
10 + '20' // 결과는 문자열 '1020' 이 된다.
true + '' // 문자열로 변경 필요 시 빈 문자열 사용 방법
null + '' // null 도 'null' 이 된다.
```

&nbsp;

**숫자 타입으로 변환**
```javascript
// 숫자 타입으로 변환 가능한 + 를 제외한 연산자들은 문자열을 숫자로 변환하여 적용
// 다른 타입을 숫자 타입으로 암묵적 타입 변환
10 - '5' // 결과는 숫자 5
10 % 'js' // 결과는 NaN (Not a Number)

// 숫자와 문자열을 비교하면 문자열을 숫자로 변환한 뒤 비교
// true, false 는 각각 1, 0 으로 대응하여 연산

// + 단항 연산자는 피연산자가 숫자 타입의 값이 아니면 숫자 타입으로 암묵적 타입 변환
console.log(+''); // 0
console.log(+true); // 1
console.log(+false); // 0
```

&nbsp;

**불린 타입으로 변환**  
자바스크립트 엔진은 불리언 타입이 아닌 값을 Truthy한 값(참으로 평가되는 값) 또는 Falsy한 값(거짓으로 평가되는 값)으로 구분한다.

**Falsy 값 (false 로 평가되는 값)**
- 0 (숫자 0)
- ‘’ (빈 문자열)
- null
- undefined
- NaN (Not a Number)

나머지는 다 Truthy 값

### 명시적 타입 변환
개발자의 의도에 따라 값의 타입을 변환하는 것

**문자열 타입으로 변환**
```javascript
// 1. String 생성자 함수를 new 연산자 없이 호출
String(null); // 'null'
String(true); // 'true'
String(10); // '10'

// 2. toString 메서드 사용
// 10 대신 null 이나 undefined 가 들어갈 경우 오류 발생
(10).toString(); // '10'
```

&nbsp;

**숫자 타입으로 변환**
```javascript
// 1. Number 생성자 함수를 new 연산자 없이 호출 (완벽히 숫자 일때만)
console.log(Number('10.01')); // 10.01
console.log(Number('10원')); // NaN

// 2. parseInt, parseFloat 함수 이용 (문자열 -> 숫자만 가능)
console.log(parseInt('10.01')); // 10
console.log(parseFloat('10.01')); // 10.01
```

&nbsp;

**논리(불린) 타입으로 변환**
```javascript
// 1. Boolean 생성자 함수를 new 연산자 없이 호출
// Falsy 6가지(false, undefined, null, 0, '', NaN)는 false 로, 나머지는 true 로 바꿔준다.

// 2. ! 부정 논리 연산자를 두 번 사용하는 방법
console.log(!''); // true
console.log(!!''); // false
console.log(!!1); // true
```
