# JavaScript
## 함수
### 정확히 외워둘 개념
- 매개변수/인자(Parameter) : 함수 정의 시 인수를 받을 이름  
인수(Argument) : 함수 호출 시 패러미터로 넘기는 값
- 함수 선언문 : 호이스팅 현상이 있어 코드 실행 전 미리 준비되어 선언보다 위에서 호출해도 동작한다.  
함수 표현식 : 선언보다 먼저 호출하면 ReferenceError 가 발생한다.
- 콜백 함수 : "지금 바로 실행할 함수"가 아니라, 다른 함수에 맡겨두었다가 필요한 시점에 호출되도록 전달하는 함수  
고차 함수 : 함수를 인수로 받는 함수

&nbsp;

**알아두자**
- JavaScript 는 오버로딩이 없다. -> 매개변수보다 인수가 더 많이 들어가면 잘리고, 적게 들어가면 undefined 로 채워진다. (arguments 로 넣은 실제 인수 확인 가능)
- JavaScript 는 블록 외내부에 같은 변수명을 작성 시, 가림 현상으로 내부 변수가 선택된다. 이 경우 내부에서 외부 변수를 불러올 방법은 없다.

### 함수 선언문
함수 : 특정 동작을 이름 붙여 재사용할 수 있게 만든 코드 묶음
```javascript
function 함수명(매개변수) { 실행 코드 }
```
```javascript
// 함수 선언문
function calculateArea(width, height) { // 1. 함수 이름과 매개변수(parameter)
    console.log(`함수 안으로 들어왔습니다. ${width} * ${height}`); // 2. 실행할 로직
    return width * height; // 3. 반환값 - 호출한 곳으로 값 전달
}

// 함수 호출 및 결과 활용
const result = calculateArea(10, 20); // 인수(argument) 전달하며 호출
console.log(result);
```

### 함수 표현식
함수 표현식 : 함수를 값으로 넣는 형식  
```javascript
const 변수명 = function(매개변수) { 실행 코드 };
```
함수 표현식 작성 시 따로 함수명을 넣을 수도 있지만 그 경우에도 함수가 담긴 변수로 호출해야 한다.
```javascript
// 일급 함수 : 함수를 값으로 취급할 수 있음. 인수로 전달할 수도 있고 프로퍼티에 속할 수도 있다.
const hi = function(name) { // 함수명 생략 가능 (함수명을 붙이더라도 호출은 변수명(hi)으로 호출해야한다)
    return `${name}님 안녕하세요!`;
};

console.log(hi('판다'));


// 함수 선언문의 호이스팅 : 함수 선언문이 코드의 가장 위로 올라간 것처럼 보이는 동작
// 함수 선언문은 코드 실행 전에 먼저 준비되기 때문에 선언 위치보다 위에서 참조가능
console.log(hello('판다'));

function hello(name) {
    return `${name} 안녕?`;
}
```

### 매개변수, 인수
매개변수 : 함수를 정의할 때 설정하는 통로  
인수 : 실제 호출할 때 넘기는 값
```javascript
// 매개변수는 함수가 호출될 때 값을 받기 위해 함수 내부에 만들어지는 지역 변수라고 볼 수 있다.
function greet(name) {
    console.log(name); // 내부에서는 자유롭게 접근 가능
    console.log(arguments); // 받은 인자값을 다 출력함 (없으면 없는대로, 초과했으면 초과한대로)
    return `${name}님 안녕하세요!`;
}

// console.log(name); // ReferenceError : 함수 내부(지역 스코프)에서만 살아 있다.


/** 인수 개수 불일치 (호출 자체가 에러나지는 않는다) */
// 필요한 인수가 안 들어가면 undefined 가 들어간다. <- javascript 엔 오버로딩이 없나? : 없나봄
console.log(greet()); // [Arguments] {}
// 초과해서 들어간 인수는 무시된다.
console.log(greet('홍길동', '이순신')); // [Arguments] { '0': '홍길동', '1': '이순신' }


/** 매개변수 기본값 활용 */
function hi(name = "가나다") { // 인수가 전달되지 않거나 undefined 가 들어오면 '가나다'가 기본값으로 쓰임
    return `${name} 안녕?`;
}
console.log(hi());
console.log(hi(undefined)); // 가나다 안녕?
console.log(hi(null)); // null 안녕?
```

### 클래스 객체?
함수 표현식을 활용하여 함수도 값으로 사용 가능
- 객체 프로퍼티에 값으로 사용
    ```javascript
    const myObject = {
        sayHi : function() {
            console.log('반갑습니다!');
        }
    };
    console.log(myObject.sayHi); // [Function: sayHi]
    myObject.sayHi(); // 함수 호출
    ```
- 다른 함수에 전달하여 사용
    ```javascript
    function manager(task, count = 1) {
        console.log(`매니저가 업무를 지시합니다.`);
        for(let i = 0; i < count; i++) {
            task();
        }
    }
    manager(sayHello);
    /** 
     * 1. 우선 sayHello() 를 호출하여 실행
     * 2. manager(sayHello()) 를 호출하여 실행함
     * 3. sayHello() 는 return 값이 없어 인수로 undefined 가 들어감.
     * 4. task 가 함수가 아니어서 task() 실행시 오류 발생 (TypeError: task is not a function)
     */
    // manager(sayHello()); // 이런 방식으로는 사용할 수 없다.
    ```
- 결과값으로 반환
    ```javascript
    function manager2(task, count = 1) {
        console.log(`매니저가 업무를 지시합니다.`);
        for(let i = 0; i < count; i++) {
            task();
        }
        return function() {
            console.log("모든 업무가 완료되었습니다.");
        }
    }
    const report = manager2(sayHello, 3); // return 반환 값 함수는 자동 실행 안됨
    report(); // 반환 받은 함수 실행
    ```

### 콜백
고차 함수 : 함수를 인수로 받는 함수  
콜백 함수 : "지금 바로 실행할 함수"가 아니라, 다른 함수에 맡겨두었다가 필요한 시점에 호출되도록 전달하는 함수  
<span style="color:#008000">계산 "시점"은 고차 함수가 결정하지만, 계산 "방식"은 외부에서 주입받은 콜백 함수가 결정한다.</span>
```javascript
// 고차 함수
function calculator(calculateCallback, a, b) {
    console.log('계산을 시작합니다.');
    // 계산 '시점'은 calculator 가 결정하지만, 계산 '방식'은 외부에서 주입받은 콜백 함수가 결정한다.
    const result = calculateCallback(a, b);
    return result;
}

// 콜백 함수
function add(a, b) {
    return a + b;
}
function multiply(a, b) {
    return a * b;
}

// 고차함수에 콜백함수를 '재료'처럼 전달
const addResult = calculator(add, 9, 8);
console.log(addResult); // 17
const multiplyResult = calculator(multiply, 9, 8);
console.log(multiplyResult); // 72
```

## Scope (범위)
- 스코프 : 변수를 사용할 수 있는 범위
- 가림 : 함수 내외부에 같은 이름의 변수가 존재할 경우 블록 안 변수가 우선적으로 지정된다.
    - JavaScript 에서는 가림 현상이 일어났을 때 함수 외부의 같은 이름의 변수를 불러올 방법이 없다.

스코프 외의 변수를 찾을 경우 ReferenceError: area is not defined 에러가 발생한다.
- 렉시컬 스코프(Lexical Scope) : 정의된 위치의 바깥 이름을 찾는다. 함수의 **정의된 위치가 아니라 선언된 위치(블록)가 중요**하다는 의미.
    ```javascript
    let label = '바깥';

    function printLabel() {
        console.log(label); // 렉시컬 스코프 : 정의된 위치의 바깥 이름을 찾는다.
    }

    label = "바깥2";

    function run() {
        const label = 'run 안쪽';
        printLabel(); // 바깥2
    }

    run();
    ```

&nbsp;

**선언 방식에 따른 범위의 차이**
|  | var | let | const |
| --- | --- | --- | --- |
| 적용 범위 | 함수 안에서 선언한 변수는 함수 안에서 공통된 지역 변수로 사용됨 | 블록 범위로 스코프를 가짐 |  |
| 재선언 / 재할당 | 같은 스코프 안에서 재선언을 허용 | 같은 스코프 안에서 재할당은 허용, 재선언은 금지 | 재선언, 재할당 금지 |
|  | var oldMessage = '처음'; var oldMessage = '변경'; | let message = 'first'; message = 'change'; | const greeting = '안녕하세요'; |
| 선언 전 사용 | undefined 로 초기화 (var 변수가 존재할 경우만 이렇게 처리됨) | ReferenceError: Cannot access '변수명' before initialization 에러 발생 |  |

&nbsp;

- var : 함수 안에서 선언하면 그 변수는 함수 안에서는 공통된 지역 변수이다.
    ```javascript
    var i = 200;

    function compareVar() {
        var i = 100;
        for(var i = 0; i < 3; i++) {
            console.log('var 안 :', i); // 0 1 2
        }
        console.log('var 밖 :', i); // 3 // 오염됐다!!
    }

    compareVar();

    console.log(i); // 200
    ```

- let : 블록 범위로 스코프를 가져 제대로 구분이 된다.
    ```javascript
    function compareLet() {
        let i = 100;
        for(let i = 0; i < 3; i++) {
            console.log('let 안 :', i); // 0 1 2
        }
        console.log('let 밖 :', i); // 100
    }

    compareLet();
    ```
