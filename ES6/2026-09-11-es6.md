# ES6
## Class
클래스는 ES6에서 처음 나왔다.
```javascript
class Student {
    // 클래스의 생성자 함수. new Student(..) 실행 시 자동으로 호춛되는 초기화 메서드
    constructor(name, score) { // 생성자에서 저장된건 각 학생 객체에 저장된다.
        this.name = name;
        this.score = score;
    }

    // 객체마다 함수를 새로 만들지 않고 Student.prototype 에 한 번 만들어 공유한다.
    getInfo() { // Student.prototype.getInfo = function() {}
        return this.name + ' : ' + this.score + '점';
    }
}

// 클래스 생성자를 호출할 때는 new 없이는 호출할 수 없다.(TypeError)
const student1 = new Student('홍길동', 80);
const student2 = new Student('유관순', 90);
```

## 화살표 함수
### 화살표 함수를 사용하는 이유
기존의 함수는 자신만의 this 가 존재하는데 화살표 함수는 자기만의 this 가 존재하지 않다. 그렇기에 외부의 this 를 사용한다.
- 일반 함수 : 자신을 this 로 사용하고 싶다.
- 화살표 함수 : 외부의 this 를 사용하고 싶다. (콜백 함수를 작성할 때 보통 화살표 함수를 주로 사용)
```javascript
const theater = {
    store : '청량리역점',
    titles : ['오디세이', '옵세션'],

    showMoveList : function() {
        console.log(this);

        // 화살표 함수는 자신만의 this 가 없고, 바깥 범위의 this 를 사용한다.
        this.titles.forEach(title => {
            console.log(this.store + ' : ' + title);
        });

        // 화살표 함수 대신 일반 함수를 넣으면 외부 함수의 this 를 자동으로 이어받지 않아 TypeError(undefined) 가 된다.
        // this.title.forEach(function(title) {
        //     console.log(this.store + ' : ' + title);
        // });
    }
};
```

## Iterable
iterable 은 값을 순서대로 하나씩 꺼낼 수 있는 값이다. 배열과 문자열이 대표적이다.
### for...of
#### 배열
```javascript
// 윈도우 + . : 윈도우 이미지
const fruits = ['🍏', '🍌', '🍓'];

// 인덱스도 값도 필요하고 순서도 세밀하게 조절하고 싶을 때
for(let i = 0; i < fruits.length; i++) {
    console.log('일반 for문 :', i, fruits[i]);
}

// 인덱스가 필요 없을 때
for(const fruit of fruits) { // for(String fruit : fruits) {} 랑 같은 효과
    console.log('for...of :', fruit);
}
```

&nbsp;

#### 문자열
문자열에서는 iterable 사용시 문자를 하나씩 차례대로 받는다.
```javascript
// 문자열에선 문자를 차례대로 받음
const message = '안녕';
for(const character of message) {
    console.log('글자', character);
}
```

## Spread
### Spread Syntax
함수의 '인수' 자리나, 배열/객체 리터럴 안에서 사용하여 배열의 요소들을 개별 값의 목록으로 펼쳐준다.
```javascript
const scores = [80, 95, 70];

// Math.max(80, 95, 70) : 전달받은 숫자 중 가장 큰 숫자를 구한다.
// console.log(Math.max(scores)); // NaN // 배열 자체는 인자로 받지 않는다.

// Spread(...) : 배열을 인수로 펼친다.
// 함수의 인수 자리에서 사용하면 배열을 하나씩 펼치는 역할을 한다.
console.log(Math.max(...scores));


const frontEnd = ['HTML', 'CSS'];
// push() 는 원본 배열에 추가.
// Spread 문법을 사용하여 새로운 배열 생성
const languages = [...frontEnd, 'JavaScript'];

// 혹은 그냥 배열을 값만 복사해서 사용하고 싶을 때 사용
const languagesCopy = [...languages];
console.log(languages === languagesCopy); // false
```

#### Spread 복사 (얕은 복사)
밖의 배열은 새로 만들어지지만 안의 객체(참조값)는 그대로 가져온다. (같은 주소값 가리킴)
```javascript
const original = [
    {name : 'Hong gil dong'}
];
const copied = [...original];
console.log(copied);

// 모든 요소를 새 대괄호 안에 펼치므로 모양은 같지만 서로 다른 배열이 만들어짐
console.log(original === copied); // false

// 밖의 배열은 새로 만들어지지만 안의 객체(참조값)는 그대로 가져온다. (같은 주소값 가리킴)
console.log(original[0] === copied[0]); // true
```

### Rest Parameter
함수의 '매개변수' 자리에 사용하여, 정해지지 않은 개수의 인수들을 하나의 '배열'로 모아서 받는다.  
나머지 인수를 배열로 모은다. 나머지 인수가 몇 개 들어올지 모를 때 주로 사용.
```javascript
// Rest 파라미터 : 나머지 인수를 배열로 모으기
function sum(...numbers) {
    let total = 0;
    console.log('받은 인수의 배열', numbers);

    for(let number of numbers) {
        total += number;
    }
    return total;
}
console.log(sum(10, 20));
```

### Spread Syntaxd 와 Rest Parameter 차이
```javascript
const prices = [1000, 2000, 3000];

// Rest Parameter : 함수의 매개변수 자리
function printToTotal(label, ...values) {
    let total = 0;
    
    for(const value of values) {
        total += value;
    }

    console.log(label, total);
}

// Spread Syntax : 호출하는 쪽에서 Spread 문법
printToTotal('합계 :', ...prices); // ('합계 :', 1000, 2000, 3000)
```

## Destructing (구조 분해 할당)
배열이나 객체의 속성을 해체하여 그 값을 개별 변수에 손쉽게 담을 수 있게 하는 표현식
### 배열 구조 분해 할당
순서대로 왼쪽 변수에 할당한다.  
const [ 할당받을 변수 이름들 ] = 배열;
```javascript
const colors = ['Red', 'Blue'];

// 배열 구조 분해 할당
const [ primaryColor, secondaryColor ] = colors;
console.log(primaryColor, secondaryColor); // Red Blue

// 기본값을 설정하지 않으면 남은 변수에는 undefined 가 나온다.
const [leader, assistant = '미정'] = ['Hong gil dong'];
console.log(leader, assistant); // Hong gil dong 미정

// Rest Paramter 로 other 변수에 배열로 남은걸 다 받는다.
const [first, ...other] = ['유관순', '장보고', '이순신'];
console.log(first, other); // 유관순 [ '장보고', '이순신' ]
```

### 객체 구조 분해 할당
순서가 아니라 프로퍼티 키 이름으로 값을 찾는다.  
const { 할당 받을 키 ; 할당 받을 새 변수, 할당 받을 키 } = 객체;
```javascript
const student = {
    name : '유관순',
    age : 16,
    major : '역사'
};

// student 중에서 해당 키 값을 가진 요소들이 왼쪽 변수 값으로 할당된다.
// 객체 구조분해는 순서가 아니라 프로퍼티 키 이름으로 값을 찾는다.
const { name, age } = student;
console.log(name, age); // 유관순 16

// name 키의 값을 lernerName 이라는 새 변수에 할당한다.
// 마찬가지로 없는 키를 찾았는데 기본값이 없으면 undefined 출력
const { name: learnerName, job = '학생' } = student;
console.log(learnerName, job); // 유관순 학생
```

### 구조 분해 할당 활용
#### 매개 변수에서의 활용
```javascript
const product = {
    name : 'keyboard',
    price : 70000
};

function printProduct(product) {
    // 구조할당으로 인수로 받은 product 의 값을 따로 할당 받음
    const { name, price } = product;

    console.log('상품명 :', name, '가격 :', price + "원");
}

// 필요한 프로퍼티를 바로 매개변수에서 구조 분해 할당
function printProduct2({ name, price }) {
    console.log('상품명 :', name, '가격 :', price + "원");
}

printProduct(product); // 상품명 : keyboard 가격 : 70000원
printProduct2(product); // 상품명 : keyboard 가격 : 70000원
```

#### 콜백에서의 활용
```javascript
const products = [
    { name : '키보드', price : 50000 },
    { name : '마우스', price : 30000 }
];

// 기존 방식
const productNames = products.map(p => p.name);
console.log(productNames);

// 객체 구조 분해 할당 적용
// 객체 구조 분해 매개변수는 소괄호로 감싸줘야한다.
const productNames2 = products.map(({name}) => name);
console.log(productNames2);
```
