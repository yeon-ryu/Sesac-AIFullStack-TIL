# I/O (입출력)

## Stream

단방향 통로로 자바에서 제공하는 클래스. 입력 스트림과 출력 스트림을 따로 구성해야 한다.

| 바이트 기반 |  | 문자 기반 |  |
| --- | --- | --- | --- |
| 입력 스트림 | 출력 스트림 | 입력 스트림 | 출력 스트림 |
| InputStream | OutputStream | Reader | Writer |
| FileInputStream | FileOutputStream | FileReader | FileWriter |

프로그램 기준으로 프로그램으로 들어오면 input, 프로그램에서 나가면 output

사용이 끝난 스트림은 반드시 닫아준다 (자원 반납)

## File

파일을 다루는 클래스 `java.io.File`

파일 자체의 정보만 다루고 파일의 내용에 대해서는 다루지 않는다.

- createNewFile() : 새 파일 생성. 새 파일을 만들면 true, 이미 파일이 존재하면 false 반환
- length() : 파일 크기(byte)
- getPath() : 파일 상대 경로
- getAbsolutePath() : 파일 절대 경로
- delete() : 파일 삭제. 성공 시 true, 실패 시 false 반환

```java
package com.ohgiraffers.section01;

import java.io.File;
import java.io.IOException;

public class Application {
    public static void main(String[] args) {
        // 실제 파일이 생긴게 아니라 파일 객체가 메모리에 생김
        File file = new File("src/com/ohgiraffers/section01/test.txt");

        try {
            // 실제 파일 생성 -> 새 파일을 만들면 true, 이미 파일이 존재하면 false
            boolean createSuccess = file.createNewFile();
            System.out.println(createSuccess);
        } catch (IOException e) {
            throw new RuntimeException(e);
        }

        System.out.println("크기 : " + file.length() + "byte");
        System.out.println("경로 : " + file.getPath());
        System.out.println("절대 경로 : " + file.getAbsolutePath());

        // 파일 삭제
        boolean deleteSuccess = file.delete();
        System.out.println(deleteSuccess);
    }
}
```

## Byte 기반 입출력

영상, 이미지 등 모든 파일을 입출력 가능하다.

텍스트를 읽고 쓰는 것에는 적합하지 않다.

### FileInputStream

파일의 데이터를 바이트 단위로 읽는 입력 스트림

**이미지, 영상, 텍스트 등 모든 파일**은 바이트로 읽을 수 있다.

다만 텍스트를 글자로 처리할 때는 Reader 계열을 사용하는 편이 알맞다. → 문자가 1byte 보다 크면 깨짐

- read() : 파일에 기록된 값을 1바이트 씩 읽어온다. 더이상 읽을 데이터가 없으면 -1 반환

```java
FileInputStream fin = null;

try {
    // 읽어올 파일 경로
    fin = new FileInputStream("src/com/ohgiraffers/section02/testInputStream.txt");

    int value;

    // read() : 파일에 기록된 값을 1바이트씩 읽어온다. 더이상 읽을 데이터가 없으면 -1을 반환
    while((value = fin.read()) != -1) {
        System.out.println(value); // 읽은 바이트를 0~255 범위의 정수로 확인
        System.out.println((char) value);
    }
} catch (FileNotFoundException e) {
    e.printStackTrace();
} catch (IOException e) {
    e.printStackTrace();
} finally {
    // 사용이 끝난 스트림은 반드시 닫아준다. (자원 반남)
    if(fin != null) {
        try {
            fin.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

### FileOutputStream

데이터를 1바이트씩 파일에 출력하는 스트림

`new FileOutputStream(path)` 의 기본 동작은 덮어쓰기라 **파일 전체가 새 출력으로 덮어쓰기**가 된다.

이어쓰기가 필요하다면 `new FileOutputStream(path, true)` 처럼 append 옵션을 선택해야 한다.

- write(기록할 바이트) : 파일을 자동 생성하고 실제 입력까지 해준다.

**try-with-resources 구문** : try 블록 안에서 스트림을 만들면 try 블록이 끝날 때 자동으로 close() 가 호출된다.

```java
try(FileOutputStream fout = new FileOutputStream("src/com/ohgiraffers/section02/testOutputStream.txt", true)) {
    // 파일이 자동으로 생성되고 쓰여진다.
    // 1. 1바이트 쓰기
    fout.write(97); // 아스키코드 97 -> a

    /* byte 배열을 이용하여 여러 바이트를 한 번에 기록
    * 10 : 개행문자 (엔터) */
    byte[] bar = new byte[] {98, 99, 100, 101, 10, 102};
    fout.write(bar);
} catch (FileNotFoundException e) {
    e.printStackTrace();
} catch (IOException e) {
    e.printStackTrace();
}
```

## 문자 기반 입출력

실행 환경의 기본 문자셋을 사용한다.

### FileReader

byte 단위가 아닌 문자 단위로 텍스트를 읽는다.

- InputStreamReader : 보조 스트림. 혼자 사용할 수 없고, 바이트 스트림을 감싸 문자 변환 기능을 추가

```java
import java.io.*;
import java.nio.charset.StandardCharsets;

public class Application3 {
    public static void main(String[] args) {
        /* FileReader : byte 단위가 아닌 문자 단위로 텍스트를 읽는다 */

        try(FileReader fr = new FileReader("src/com/ohgiraffers/section02/testReader.txt")) {
            int value;
            while((value = fr.read()) != -1) {
                System.out.println((char) value);
            }

        } catch (FileNotFoundException e) {
            e.printStackTrace();
        } catch (IOException e) {
            e.printStackTrace();
        }

        // InputStreamReader : 보조 스트림으로 혼자 사용할 수 없고, 바이트 스트림을 감싸 문자 변환 기능을 추가
        try(Reader reader = new InputStreamReader(
                new FileInputStream("src/com/ohgiraffers/section02/testReader.txt")
                , StandardCharsets.UTF_8 // 바이트를 해석할 문자 규칙
        )) {
            int value;
            while((value = reader.read()) != -1) {
                System.out.println((char) value);
            }
        } catch (FileNotFoundException e) {
            e.printStackTrace();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

### FileWriter

문자 데이터를 텍스트 파일에 쓰는 출력 스트림

```java
import java.io.*;
import java.nio.charset.StandardCharsets;

public class Application4 {
    public static void main(String[] args) {
        /*
        * FileWriter : 문자 데이터를 텍스트 파일에 쓰는 출력 스트림
        * FileReader 와 마찬가지로 실행 환경의 기본 문자셋을 사용
        * */

        try(FileWriter fw = new FileWriter("src/com/ohgiraffers/section02/testWriter.txt")) {
            fw.write(97); // a
            fw.write('A');
            fw.write(new char[] {'a', 'p', 'p', 'l', 'e'});
            fw.write("\n헬로헬로 반갑");
            fw.write("\n숫자는 쓰고 싶으면 문자열로 바꿔서 쓰는게 맞겠네");
        } catch (IOException e) {
            e.printStackTrace();
        }

        try(Writer writer = new OutputStreamWriter(
                new FileOutputStream("src/com/ohgiraffers/section02/testWriterUTF8.txt")
                , StandardCharsets.UTF_8
        )) {
            writer.write("UTF-8 로 지정한한글 텍스트");
        } catch (FileNotFoundException e) {
            e.printStackTrace();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

## 보조 스트림

### BufferedWriter / BufferedReader

Buffer : 데이터를 모아두는 공간

기본 스트림(FileWriter / FileReader)을 감싸서 사용하는 보조 스트림

데이터를 바로바로 파일에 쓰거나 읽는 것보다, 버퍼를 거치면 입출력 횟수를 줄일 수 있다.

- flush() : 버퍼에 남아있는 내용 밀어낸다. (이래야 실제로 쓰이거나 한다)
- readLine() : 읽어올 게 없으면 null 을 반환한다.

```java
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.IOException;

public class Application {
    public static void main(String[] args) {
        /* BufferedWriter / BufferedReader
        * - 기본 스트림(FileWriter / FileReader)을 감싸서 사용하는 보조 스트림이다.
        * - 버퍼는 데이터를 모아두는 공간이다.
        * - 데이터를 바로바로 파일에 쓰거나 읽는 것보다, 버퍼를 거치면 입출력 횟수를 줄일 수 있다.
        *  */

        // try-with-resources 구문에서는 try 끝날 때 자동으로 알아서 자원을 close() 해주는데, 그 전에 flush() 가 포함되어 있다.
        try(BufferedWriter bw = new BufferedWriter(
                new FileWriter("src/com/ohgiraffers/section03/filterstream/testBuffered.txt")
        )) {
            bw.write("안녕");
            bw.write("반가워");
        } catch (IOException e) {
            e.printStackTrace();
        }

        try {
            BufferedWriter bw2 = new BufferedWriter(new FileWriter("src/com/ohgiraffers/section03/filterstream/testBuffered.txt"));
            // 이렇게 하면 버퍼에 쌓이기에 바로 저장 되지 않는다.
            bw2.write("sssss");
            // 버퍼에 있는 데이터를 방출
            bw2.flush();
        } catch (IOException e) {
            throw new RuntimeException(e);
        }
    }
}
```

### InputStreamReader / OutputStreamReader

- byte 기반 스트림을 char 기반 스트림으로 연결할 때 사용
- System.in 은 키보드 입력을 바이트 단위로 받는 inputStream 이다.
- inputStreamReader 는 그 바이트를 문자로 해석해 Reader 로 바꿔준다.
- BufferedReader 는 Reader 를 감싸서 버퍼 기능과 readLine()을 제공한다.

`BufferedReader br = new BufferedReader(new InputStreamReader(System.in))`

System.in → 키보드 바이트 입력 → InputStreamReader → 바이트를 문자로 변환 → BufferedReader → readLine() 제공 → 프로그램의 String

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class Application2 {
    public static void main(String[] args) {

        /* 형변환 보조스트림(InputStreamReader / OutputStreamWriter)
        * - byte 기반 스트림을 char 기반 스트림으로 연결할 때 사용
        * - System.in 은 키보드 입력을 바이트 단위로 받는 inputStream 이다.
        * - inputStreamReader 는 그 바이트를 문자로 해석해 Reader 로 바꿔준다.
        * - BufferedReader 는 Reader 를 감싸서 버퍼 기능과 readLine()을 제공한다. */

        try(BufferedReader br = new BufferedReader(new InputStreamReader(System.in))) {
            System.out.print("문자열 입력 : ");
            String value = br.readLine();
            System.out.println("value = " + value);
        } catch (IOException e) {
            throw new RuntimeException(e);
        }
    }
}
```

## Properties

Hashtable 을 상속받아 구현한 것으로 (String, String) 형태로 저장한다.

주로 환경 설정과 관련된 속성을 저장하는데 사용한다.

- setProperty(key, value) : Properties 객체에 데이터를 넣는다. 순서는 보장하지 않는다.
- store(writer, 파일 설명) : Properties 객체 내용을 writer 로 출력한다
- load(reader) : reader 로 읽어와서 Properties 객체에 저장한다.
- getProperty(key) : Properties 객체에 있는 데이터를 key 값으로 가져온다.

```java
// Properties 객체에 데이터 추가
Properties prop = new Properties();
prop.setProperty(key, value);

// 실제로 파일에 쓰기
try(Writer writer = new OutputStreamWriter(new FileOutputStream(filePath), StandardCharsets.UTF_8)) {
    // 현재 객체에 들어있는 key value 값을 writer 로 보낸다. 오른쪽은 파일 설명
    prop.store(writer, "application settings");
}

Properties loadedProp = new Properties();

try(Reader reader = new InputStreamReader(new FileInputStream(filePath), StandardCharsets.UTF_8)) {
    loadedProp.load(reader);
}
```

# Enum

enum 클래스는 하나의 타입이 되고 그 안에 선언된 것들은 해당 타입의 상수로 인식된다. 열거형 상수라 부른다.

- ordinal() : 상수의 선언 위치를 0부터 반환
- name() : 상수의 소스 이름을 문자열로 반환

```java
public enum Subjects {
    JAVA,
    MYSQL,
    JDBC,
    HTML,
    CSS
}
```

```java
public class Application {
    public static void main(String[] args) {
//        printSubject(2); // Subjects 타입이 아니므로 전달 불가
        printSubject(Subjects.HTML);

        // 선언된 상수 순회
        for(Subjects s : Subjects.values()) {
//            s.ordinal(); // 형재 상수의 선언 위치를 0부터 반환
//            s.name(); // 같은 상수의 소스 이름을 문자열로 반환
            System.out.println((s.ordinal() + 1) + ". " + s.name());
        }
    }

    public static void printSubject(Subjects subjects) {
        System.out.println("전달받은 과목 : " + subjects.toString());
    }
}
```

## 추가 속성이 있는 enum

아무것도 없다면 `,` 으로 구분만 하지만, 속성이 있으면 최후에 `;` 로 끝내야 한다.

```java
import java.util.Locale;

public enum UserRole {
    GUEST("게스트"),
    CONSUMER("구매자"),
    PRODUCESR("판매자"),
    ADMIN("관리자")
    ;

    private final String description;

    private UserRole(String description) {
        System.out.println("UserRole 생성자 호출 " + description);
        this.description = description;
    }

    public String getDescription() {
        return description;
    }

    public String getNameToLowerCase() {
        // this.name() : 선언 이름을 문자열로 반환
        return this.name().toLowerCase();
    }
}
```

```java
public class Application {
    public static void main(String[] args) {
        // UserRole 의 모든 상수의 생성자를 호출하여 초기화 한다.
        UserRole admin = UserRole.ADMIN;    // new 키워드로 객체 생성

        // 이미 위에서 초기화를 끝냈기에 두번째 불렀을 때는 생성자를 호출하지 않는다.
        UserRole guest = UserRole.GUEST;    // 이미 위에서 준비된 상수 참조

    }
}
```
