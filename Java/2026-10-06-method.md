# JDK
- **JDK (Java Develpment Kit)** : 자바를 개발할 때 필요한 컴파일러(javac) 나 자바콘솔, javadoc 등과 같은 키트를 포함하고 있어서 프로그램을 생성하고 컴파일을 할 수 있다.
- **JRE(Java Runtime Environment)** : 자바 실행 환경. 자바로 만들어진 프로그램은 JRE 가 있어야 기동이 가능한데, JRE 는 자바 가상머신과 자바 클래스 라이브러리, 자바 명령을 포함한 자바 실행에 필요한 패키지를 가지고 있다. (자바를 개발하지 않고 실행만 할 경우 JRE 만 있으면 가능)
- **JVM(Java Virtual Machine)** : 윈도우, Mac 등 어떤 운영체제 위에든 설치 가능한 자바만을 위해 존재하는 가상의 컴퓨터

JDK = JRE + 개발도구, 컴파일러 등  
JRE = JVM + 라이브러리, 기타  

Java 실행 순서 : **Java → Java Compiler → Java Byte Code (중간 언어) → JVM → 운영체제**

- Java Compiler : 코드를 기계어로 변경. 변경 시 문제가 있을 경우 오류를 발생 시킨다.
- Java Byte Code : 중간 언어. 바이트 코드(.class)
- JVM : 바이트 코드를 운영체제에 맡게 실행시켜 준다.

# IDE
통합 개발 환경 (Integrated Development Environment)  
코딩, 디버그, 컴파일, 배포 등 프로그램 개발에 필요한 작업을 지원해주는 소프트웨어
- Eclipse
- IntelliJ : 2001년 출시. 2025년 무료 버전인 커뮤니티와 유료 버전인 Ultimate 가 하나로 합쳐졌다. 무료 기능은 계속 무료로 제공된다. 이클립스와 다르게 워크스페이스 개념이 없기에 프로젝트 단위로 생성하여 개발을 진행한다.

## 실행 파일
main 메서드가 존재해야 실행할 수 있다. (JVM 이 프로그램 시작점으로 main 메서드를 찾아서 실행하기 때문)  
main 메서드가 각 클래스에 하나씩 여러개 존재해도 실행한 클래스의 main 만 실행되어 문제 없이 실행된다.
```java
public class Application {
    public static void main(String[] args) {
        
    }
}
```

## 리터럴한 값
- 정수와 실수의 연산 : 실수 결과값
- 문자('a')의 연산 : 유니코드로 계산된다
- 문자열과 연산 : 다른 형태의 값들도 문자열로 취급되어 문자열 합치기가 된다
- 논리값 연산 : 숫자처럼 산술 연산을 할 수 없다

## 변수
`자료형 변수명 = 초기값;`

### 기본 자료형 (primitive type) 8 가지
- byte : 1byte
- short : 2byte
- int : 4byte
- long : 8byte
- float : 4byte
- double : 8byte
- char : 2byte
- boolean

### 변수 명명 규칙
1. 컴파일 에러 발생
   - 동일한 범위 내에서 동일한 변수명을 가질 수 없다.
   - 예약어 사용 불가 (java 에서 미리 사용하겠다고 컴파일러와 약속한 키워드)
   - 대소문자를 구분한다.
   - 숫자로 시작할 수 없다.
   - 특수기호는 '_' 와 '$' 만 사용 가능
2. 에러를 발생시키지는 않지만 암묵적 규칙
   - 합성어로 이루어진 경우 첫 단어는 소문자, 두 번째 시작 단어는 대문자로 시작한다(카멜 케이스)
   - 영어로 변수명 명명
   - 변수 안에 저장된 값이 어떤 의미를 가지는지 명확하게 표현
   - 전형적인 변수 이름이 있다면 가급적 사용
   - boolean 은 의문문으로 가급적 긍정 형태로 네이밍

## 상수
변하지 않는 값을 저장해두기 위한 메모리상의 공간  
상수 선언 시 자료형 앞에 final 키워드를 붙인다.  
한번 초기화 하면 그 이후 재 대입할 수 없다.
```java
final int AGE;
AGE = 20;
```

### 암묵적 규칙
- 영문자 대문자 혹은 숫자만 사용
- 단어와 단어 연결은 언더스코어(_)를 사용

## overflow
자료형이 저장할 수 있는 최대 범위를 넘어가는 현상
```java
// overflow : 자료형이 저장할 수 있는 최대 범위를 넘어가는 현상
byte bnum = 127; // byte 의 최대 저장 범위
bnum++; // 1 을 증가
System.out.println(bnum); // -128 (1 이 늘어나 부호 연산자가 1이 되어 마이너스가 됐다)

// 언더플로우 : 최솟값보다 작아져 반대편 최대값으로 돌아가는 현상
byte bnum2 = -128;
bnum2--;
System.out.println(bnum2); // 12
```

결과값이 클 경우, 결과 타입만 넓은 범위 타입으로 바꾸더라도 계산할 시점에 오버플로우가 발생한다.  
그렇기에 피연산자 중 하나를 미리 넓은 범위 타입으로 변환하면 전체 계산이 해당 타입으로 진행된다.
```java
int firstNum = 1000000;
int secondNum = 700000;

// 일반 오버플로우
int multi = firstNum * secondNum; // -79669248

// 계산 시 이미 두 값이 int 이므로 연산 중에 이미 오버플로우가 발생
long longNum = firstNum * secondNum; // -79669248

// 피연산자 하나를 미리 long 으로 변환하면 전체 계산이 long 으로 처리
long result = (long) firstNum * secondNum; // 700000000000
```

## 형변환
- 자동 형변환
  - 서로 다른 숫자 타입을 연산하면 자바가 두 값을 함께 계산할 수 있는 타입으로 맞춘다. : 일반적으로 표현 범위가 더 넓은 타입으로 자동 변환한 뒤 연산
  - 정수는 실수로 자동 형변환 된다.
    ```java
    long lnum = 8l;
    float fnum = lnum; // 8.0
    ```
- 강제 형변환
  - 바꾸려는 자료형으로 캐스트 연산자를 이용하여 형변환 `(바꿀 자료형) 값`
  - 실수를 정수로 변경 시 강제 형변환 필요
    ```java
    float fnum = 4.0f;
    long lnum = (long) fnum; // 4
    ```

## 연산자
- 산술 연산자(+, -, *, /, %)
  - `/` 사용 시, 정수끼리 나눈 결과는 소수 부분을 버린다.
- 산술 복합 대입 연산자(+=, -=, *=, /=, %=)
- 증감 연산자(++, --)
  - num++ : 현재 값을 먼저 사용한 뒤 1 증가
  - ++num : 먼저 1을 증가시킨 뒤 증가한 값 사용
- 비교 연산자(==, !=, >, <, >=, <=)
  - 문자열 비교 : equals() 사용. String 은 기본 자료형이 아니라 객체이기에 메모리 주소값을 비교하기에 부정확할 수 있다.
- 논리 연산자 : 자바는 논리 연산에 boolean 값만 사용 가능하다. (Truthy 또는 Falsy 한 값은 존재하지 않는다.)
  - 논리 연결 연산자(&&, ||)
  - 논리 부정 연산자(!)
  - 배타적 논리합(^)
  ```java
    /* 단축 평가 : boolean 값으로 결과를 돌려준다.
    * && : 앞의 결과가 false 이면 뒤를 실행 안함
    * || : 앞의 결과가 true 이면 뒤를 실행 안함 */

    int num2 = 10;
    boolean result1 = false && ++num2 > 0;
    System.out.println("result1 = " + result1);
    // 단축평가로 증감 연산자가 실행되지 않아 num2 는 10 이 유지된다.
  ```
- 삼항 연산자 : `(조건식) ? 참일 때 결과값 : 거짓일 때 결과값`

## 메소드
`접근제어자 리턴타입 메소드명 (매개변수) { 실행구문 }`  
메소드는 종료되면 호출했던 위치로 돌아간다.
```java
public class Application1 {
    public static void main(String[] args) {
        /* 메소드
        * 어떤 특정 작업을 수행하기 위한 명령문의 집합 */

        /* 호출 방법
        * 클래스명 사용할이름 = new 클래스명();  // 객체 생성
        * 사용할이름.메소드명();                // 메소드 호출
        */

        System.out.println("main 호출됨");

        Application1 app1 = new Application1();
        app1.methodA();
    }

    // 접근제어자 리턴타입 메소드명 (매개변수) { 실행 구문 }
    public void methodA() {
        System.out.println("methodA() 호출함");
        methodB();
        System.out.println("methodA() 종료됨");
    }

    public void methodB() {
        System.out.println("methodB() 호출함");
        System.out.println("methodB() 종료됨");
    }
}
```
```java
public class Application2 {
    public static void main(String[] args) {
        /* 전달인자(argument)와 매개변수(parameter)
        * - 메소드를 호출할 때 넘겨주는 값을 '전달인자'라고 하며
        * - 메소드에서 이 값을 받기 위해 선언된 변수를 '매개변수'라고 한다 */

        // 클랙스 객체(인스턴스) 생성
        // Application2 : 사용자정의 자료형
        Application2 app2 = new Application2();

        // 매개변수의 타입, 개수, 순서를 정확하 맞춰서 전달해야 한다.
        app2.printUserInfo("판다", 3, 'M');

        /* void : 반환값이 없다는 뜻
        * void 가 아닌 반환 타입을 작성했다면 그 타입에 맞는 값을 반드시 반환해야 한다.
        * 반환된 값은 변수에 저장하거나 다른 메소드의 전달인자로 즉시 사용할 수 있다. */
        String message = app2.createMessage();
        System.out.println("message = " + message);
    }

    // void 메소드는 반환값이 없음을 뜻함, 마지막 줄에 return을 생랼할 수 있다.
    public void printUserInfo(String name, int age, char gender) {
        System.out.println("이름 : " + name + ", 나이 : " + age + ", 성별 : " + gender);
    }

    // 반환 타입에 맞는 반환 값을 작성해야 한다.
    public String createMessage() {
        return "hello world!!";
    }
}
```

### static
`클래스명.메스도명();`  
특정 객체가 아니라 클래스에 속하므로 객체를 만들지 않고 호출한다.
```java
// Application4.java
public class Application4 {
    public static void main(String[] args) {
        int first = 100;
        int second = 50;

        // non-static 메소드의 경우
        Calculator calculator = new Calculator();
        int min = calculator.minNumberOf(first, second);
        System.out.println("min = " + min);

        // static 메소드의 경우
        // 동일 클래스 내에 선언됐을 경우 클래스명 부분을 생략 가능
        int max = Calculator.maxNumberOf(first, second);
        System.out.println("max = " + max);

        // non-static 방식으로 호출도 가능은 하다
        // 객체로 접근할 수 있지만 권장하지 않음
        int max2 = calculator.maxNumberOf(3, 1);
        System.out.println("max2 = " + max2);
    }
}

// Calculator.java
public class Calculator {
		// 같은 클래스에서 사용할 것이니 protected 를 사용해봄
    public int minNumberOf(int first, int second) {
        return first > second ? second : first;
    }

    public static int maxNumberOf(int first, int second) {
        return first > second ? first : second;
    }
}
```

## package 와 import
`패키지명.클래스명`이 전체 클래스명이다.  
다른 패키지에 있는 클래스를 사용해야할 때 import 를 이용해서 짧게 사용할 수 있다.  
import static 으로 static 함수만을 import 해서 사용할 수 있다. (권장하지 않음)
```java
package com.ohgiraffers.section02.package_and_import;

//import com.ohgiraffers.section01.method.Calculator;

public class Application1 {
    public static void main(String[] args) {
        com.ohgiraffers.section01.method.Calculator calc = new  com.ohgiraffers.section01.method.Calculator();
        int min = calc.minNumberOf(30, 20);
        System.out.println("min = " + min);

        int max = com.ohgiraffers.section01.method.Calculator.maxNumberOf(30, 20);
        System.out.println("max = " + max);
    }
}
```
```java
package com.ohgiraffers.section02.package_and_import;

import com.ohgiraffers.section01.method.Calculator;

// 코드에서 어떤 클래스에 정의된 기능인지 바로 파악하기 힘들기에 권장되지 않음
import static com.ohgiraffers.section01.method.Calculator.maxNumberOf;

public class Application1 {
    public static void main(String[] args) {
        Calculator calc = new  Calculator();
        int min = calc.minNumberOf(30, 20);
        System.out.println("min = " + min);

        int max = Calculator.maxNumberOf(30, 20);
        System.out.println("max = " + max);
        
        // static import 해서 클래스명 생략 사용 가능
        int max2 = maxNumberOf(10, 20);
        System.out.println("max2 = " + max2);
    }
}
```
