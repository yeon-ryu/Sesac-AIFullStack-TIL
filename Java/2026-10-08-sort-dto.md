# 배열
## 정렬
### 선택 정렬

정렬되지 않은 범위에서 가장 작은 값의 위치를 찾고, 그 값을 정렬되지 않은 범위의 첫 번째 값과 교환하는 과정을 반복한다.

왼쪽부터 제일 작은 값이 배치되게 된다

```java
int[] arr = {2, 5, 4, 6, 1, 3};

/*
 * i : 가장 작은 값을 놓을 위치
 * minIndex : 실제로 가장 작은 값이 발견된 위치
 * j : 남은 값들을 검사하는 위치
 * */
for (int i = 0; i < arr.length - 1; i++) {
    int minIndex = i;   // 우선 현재 위치의 값이 가장 작다고 가정

    for (int j = i + 1; j < arr.length; j++) {
        if (arr[minIndex] > arr[j]) {
            minIndex = j;
        }
    }
    // 찾은 최소값(arr[minIndex])과 현재 자리(arr[i]) 값을 교환
    int temp = arr[minIndex];
    arr[minIndex] = arr[i];
    arr[i] = temp;

    System.out.println((i + 1) + "회차 정렬 후 : " + Arrays.toString(arr));
}
System.out.println("정렬 후 : " + Arrays.toString(arr));
```

### 버블 정렬

인접한 두 요소를 비교하여,큰 값을 오른쪽으로 계속 이동시킨다. 한 회차가 끝나면 가장 큰 값이 배열의 맨 뒤에 위치하게 된다.

오른쪽부터 제일 큰 값이 배치되게 된다

```java
import java.util.Arrays;

public class Application3 {
    public static void main(String[] args) {
        // 버블 정렬
        int[] arr = {2, 4, 5, 3, 1};

        // i : 정렬이 확정된 영역의 시작 인덱스 (뒤에서부터) / 시작 인덱스 뒤는 건드리지 않는다.
        for(int i = arr.length - 1; i > 0; i--) {
            // j : 비교할 대상의 인덱스 (앞에서부터)
            for(int j = 0; j < i; j++) {
                if(arr[j] > arr[j + 1]) {
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                }
            }
            System.out.println((i + 1) + "회차 정렬 후 : " + Arrays.toString(arr));
        }

        System.out.println(Arrays.toString(arr)); // 제대로 오름차순으로 정렬되었다
    }
}
```

### Arrays.sort()

자바가 제공하는 배열 정렬 기능

int[] 는 별도의 비교 함수를 전달하지 않아도 숫자 오름차순으로 제공된다.

```java
import java.util.Arrays;

public class Application4 {
    public static void main(String[] args) {
        int[] arr = {2, 5, 4, 6, 1, 3};
        Arrays.sort(arr);
        System.out.println(Arrays.toString(arr));
    }
}
```

# 클래스와 객체

## 사용자 정의 타입

필드는 기본적으로 default 접근 제한자가 적용되어 있다.

```java
public class Member {
    /* [클래스]
    * 객체('회원')(Instance)가 어떤 데이터(속성)와 어떤 기능(메소드)을 가져야 하는지 정의한다.
    * 이 파일은 실제 회원을 만들기 위한 정의서일 뿐이다. */

    /* [필드]
    * 클래스 내부에 선언하여 객체 또는 클래스가 관리하는 데이터를 나타내는 변수이다.
    * '회원' 이라는 객체는 아래와 같은 속성(데이터)들을 가진다. */

    // 기타 등등
    
    @Override
```

```java
public class Application {
    public static void main(String[] args) {

         /* [사용자 정의 자료형 사용하기]
         * 1. 객체가 가져야할 데이터와 기능을 클래스로 정의한다.
         * 2. new 연산자를 통해 클래스에 정의된 객체를 생성한다. (Heap)
         * 3. 생성된 객체를 가리키는 참조 변수를 선언하고 참조값을 저장한다. (Stack) */

        // 자료형 변수명 = new 클래스명();
        Member member = new Member("판다", 5);

        // 생성된 객체(인스턴스)의 필드(속성)에 값 대입
        // '.'(참조 연산자)를 이용한다.
        member.setId("user01");
        member.setPwd("pass01");
        member.gender = 'F';
        member.hobby = new String[]{"볼링", "배드민턴", "영화"};

        System.out.println(member.toString());
    }
}
```

## 캡슐화 (접근 제한자)

캡슐화 : 자체 규칙 등으로 인한 유효화 등을 위하여 필드에 직접적인 접근을 막고 객체가 제공하는 메소드를 통해 접근하게 만든다. → 객체의 상태를 정상적으로 유지한다.

접근 제한자 : 클래스 혹은 클래스의 멤버에 참조 연산자로 접근할 수 있는 범위를 제한하기 위한 키워드

- (-) private :해당 클래스 내부에서만 접근 허용
- (~) default :동일 패키지에서 접근 허용
- (#) protected :동일 패키지 및 상속 관계에서 접근 허용
- (+) public :모든 패키지에서 접근 허용

필드,메소드,생성자에는 목적에 따라 위 접근 제한자를 사용할 수 있다.

다른 클래스 안에 들어있지 않은 최상위 클래스에는 public또는 default만 사용 가능하다. (클래스에 적용한다는 의미임)

- Getter(접근자) :내부 필드의 값을 외부에 반환하는 메서드
- Setter(변경자) :외부에서 전달된 값을 받아,내부 필드의 값을 설정 또는 변경하는 역할

```java
public class Children {
    /*
    * [접근 제한자]
    * 클래스 혹은 클래스의 멤버에 참조 연산자로 접근할 수 있는 범위를 제한하기 위한 키워드
    * (-) private : 해당 클래스 내부에서만 접근 허용
    * (~) default : 동일 패키지에서 접근 허용
    * (#) protected : 동일 패키지 및 상속 관계에서 접근 허용
    * (+) public : 모든 패키지에서 접근 허용
    *
    * 필드, 메소드, 생성자에는 목적에 따라 위 접근 제한자를 사용할 수 있다.
    * 다른 클래스 안에 들어있지 않은 최상위 클래스에는 public 또는 default 만 사용 가능하다.
    * */

    private String nickname;
    private int age;

    public Children() { super(); }

    public Children(String nickname, int age) {
        super();
        this.nickname = nickname;
        this.age = age;
    }

    /*
    * [Getter / Setter 메소드]
    * Getter(접근자) : 내부 필드의 값을 외부에 반환하는 메서드
    * Setter(변경자) : 외부에서 전달된 값을 받아, 내부 필드의 값을 설정 또는 변경하는 역할
    * */

    public String getNickname() {
        return nickname;
    }

    public void setNickname(String nickname) {
        // 객체 필드 <- 매개변수 값 대입
        this.nickname = nickname;
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        if(age < 0) {
            System.out.println("나이는 음수로 설정할 수 없습니다.");
            return;
        }
        this.age = age;
    }

    @Override
    public String toString() {
        return "Children{" +
                "nickname='" + nickname + '\'' +
                ", age=" + age +
                '}';
    }
}
```

```java
public class Application {
    public static void main(String[] args) {
        /* */
        Children child1 = new Children();
        child1.setNickname("튼튼이"); // setter 메소드로 설정
        child1.setAge(-10);

        System.out.println(child1.getNickname());
        System.out.println(child1.toString());
    }
}
```

## 추상화

추상화 : 복잡한 내부 구현은 숨기고, 외부에는 필요한 기능만 의미 있는 이름으로 보여주는 것

로직을 몰라도 메서드를 그냥 사용하고 결과값만 받는다.

```java
// Repository 의 행동 흐름
public class Car {
    private boolean isOn;   // 시동 상태
    private int speed;      // 현재 시속

    // 시동을 거는 기능
    public void turnOn() {
        if(isOn) {
            System.out.println("이미 시동이 걸려있다.");
            return;
        }

        this.isOn = true;
        System.out.println("시동을 걸었다. 출발 준비 완료.");
    }

    // 앞으로 가는 기능
    public void go() {
        if(!isOn) {
            System.out.println("시동을 먼저 걸어주세요.");
            return;
        }

        System.out.println("앞으로 움직입니다.");
        this.speed += 10;
        System.out.println("현재 시속은 " + speed + "km/h 입니다.");
    }

    // 멈추는 기능
    public void stop() {
        if(!isOn) {
            System.out.println("시동이 걸려있지 않습니다.");
            return;
        }
        if(speed > 0) {
            this.speed = speed/2;
            System.out.println("서서히 멈춥니다. 시속 " + speed + "km/h 운행 중.");
        } else {
            System.out.println("차는 이미 멈춰있습니다.");
        }
    }

    public void turnOff() {
        if(!isOn) {
            System.out.println("시동은 이미 꺼져있습니다.");
            return;
        }
        if(speed > 0) {
            System.out.println("먼저 차를 멈춰주세요.");
        } else {
            this.isOn = false;
            System.out.println("시동이 꺼집니다. 운행 종료.");
        }
    }
}
```

```java
// Service 의 행동 흐름
public class CarRacer {
    // 자신의 자동차를 가지고 있다 (소유 관계 / has-a 관계)
    // 차가 낙장불입이라니
    private final Car myCar = new Car();

    // 시동을 걸도록 명령
    public void startUp() {
        myCar.turnOn();
    }

    // 엑셀 밟도록 명령
    public void stepAccelerator() {
        myCar.go();
    }

    // 브레이크 밟도록 명령
    public void stepBreak() {
        myCar.stop();
    }

    // 시동 끄도록 명령
    public void turnOff() {
        myCar.turnOff();
    }
}
```

```java
import java.util.Scanner;

public class Application {
    public static void main(String[] args) {
        /* [추상화]
        * 복잡한 내부 구현은 숨기고, 외부에는 필요한 기능만 의미 있는 이름으로 보여주는 것
        * 프로그램에서 필요한 특징과 기능만 골라 객체로 표현하고,
        * 사용하는 쪽에는 복잡한 내부 처리 대신에 필요한 기능을 보여주는 설계 방식
        * */

        // Controller 의 행동 흐름
        // 카 레이서 객체 생성
        CarRacer racer = new CarRacer();

        Scanner sc = new Scanner(System.in);

        while(true) {
            System.out.print("1. 시동 걸기\t");
            System.out.print("2. 액셀 밟기\t");
            System.out.print("3. 브레이크 밟기\t");
            System.out.print("4. 시동 끄기\t");
            System.out.println("0. 프로그램 종료");
            System.out.print("메뉴 선택 : ");

            int no = sc.nextInt();

            switch (no) {
                // 사용자는 카레이서에게 요청
                case 1:
                    racer.startUp();
                    break;
                case 2:
                    racer.stepAccelerator();
                    break;
                case 3:
                    racer.stepBreak();
                    break;
                case 4:
                    racer.turnOff();
                    break;
                case 0:
                    System.out.println("프로그램을 종료합니다.");
                    return;
                default:
                    System.out.println("잘못된 번호를 선택하였습니다.");
            }
        }
    }
}
```

## DTO

Data Transfer Object (데이터 전송 객체)

여러 데이터를 하나로 묶어 전달하기 위한 객체

기본적으로 비지니스 로직을 넣지 않는다.

클라이언트에서 받아올 때는 기본 생성자와 getter/setter 를 이용해서 받아온다.

```java
public class MemberDTO {
    /* DTO(Data Transfer Object)
    * 여러 데이터를 하나로 묶어 전달하기 위한 객체 */

    private int number;
    private String name;
    private int age;
    private char gender;
    private double height;
    private boolean isActivated;

    public MemberDTO() {
    }

    public MemberDTO(int number, String name, int age, char gender, double height, boolean isActivated) {
        this.number = number;
        this.name = name;
        this.age = age;
        this.gender = gender;
        this.height = height;
        this.isActivated = isActivated;
    }

    public int getNumber() {
        return number;
    }

    public void setNumber(int number) {
        this.number = number;
    }

    // 기타 생략

    public boolean isActivated() {
        return isActivated;
    }

    public void setActivated(boolean activated) {
        isActivated = activated;
    }

    @Override
    public String toString() {
        return "MemberDTO{" +
                "number=" + number +
                ", name='" + name + '\'' +
                ", age=" + age +
                ", gender=" + gender +
                ", height=" + height +
                ", isActivated=" + isActivated +
                '}';
    }
}
```

```java
public class Application {
    public static void main(String[] args) {

//        MemberDTO member = new MemberDTO(1, "판다", 5, 'F', 161, true);
        MemberDTO member = new MemberDTO();

        member.setAge(5);
        member.setGender('F');
```

### 생성자

생성자를 생성하지 않으면 자동으로 기본 생성자를 추가해준다.

기본 생성자 : 클래스에 생성자가 하나도 없다면 자바 컴파일러가 기본 생성자를 자동으로 추가해준다. 하지만 매개변수 있는 생성자가 하나라도 있다면, 컴파일러가 기본 생성자를 자동으로 추가해 주지 않는다.

```java
import java.util.Date;

public class User {

    private String id;
    private String pwd;
    private String name;
    private Date enrollDate;

    /*
    * [생성자 작성 규칙]
    * 1. 이름이 클래스명과 반드시 동일해야 한다.
    * 2. 반환 타입(void, int 등)을 쓰지 않는다.
    *
    * 접근제한자 클래스명(매개변수) { 필드 초기화 코드 }
    * */

    // 1. 기본 생성자
    public User() {
        System.out.println("User 클래스의 기본 생성자 호출됨...");
    }

    // 2. 매개변수 있는 생성자
    public User(String id, String pwd, String name) {
        this.id = id;
        this.pwd = pwd;
        this.name = name;
        System.out.println("id, pwd, name 을 초기화 하는 생성자 호출...");
    }

    public User(String id, String pwd, String name, Date enrollDate) {
        this.id = id;
        this.pwd = pwd;
        this.name = name;
        this.enrollDate = enrollDate;
    }

    // getter setter 생략

    public String getInformation() {
        return "User : " + this.id + " " + this.pwd + " " + this.name + " " + this.enrollDate;
    }
}
```

```java
public class Application {
    public static void main(String[] args) {
        /*
        * 생성자는 new 로 객체를 만들 때 호출되어 객체의 초기 상태를 정한다.
        * 기본 생성자와 매개변수 있는 생성자를 차례대로 호출하며
        * setter 로 나중에 값을 넣는 방식과 생성 시점에 필요한 값을 전달하는 방식을 비교한다.
        * */

        // 기본 생성자 호출
        User user = new User();
        user.setName("판다");
        System.out.println(user.getInformation());

        // 매개변수 있는 생성자
        User user1 = new User("user01", "pass01", "판다");
        System.out.println(user1.getInformation());
    }
}
```
