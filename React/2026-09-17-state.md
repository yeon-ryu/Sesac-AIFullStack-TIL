# React
## State
변경할 수 있는 상태값
- props : 부모가 전달, 자식이 직접 수정하지 않음
- state : 컴포넌트 내부에서 관리, setter로 변경

### useState
useState : hooks 의 하나. 함수형 컴포넌트에서 State 를 사용할 수 있게 해주는 함수. 리액트가 바뀐걸 감지하고 리렌더링 할 수 있게 해준다.  
Hook : 함수형 컴포넌트가 React 의 기능을 사용할 수 있게 연결해주는 함수  
- 호출 방식
    ```jsx
    const { useState } = React;
    const [ 상태 값, 상태 변경 함수(setter) ] = useState(상태초기값);
    ```

- 예시
    ```html
    <div id="root"></div>
    <script type="text/babel">
        /*
            useState Hook
            - 함수형 컴포넌트에서 State 를 사용할 수 있게 해주는 함수
            - Hook : 함수형 컴포넌트가 React 의 기능을 사용할 수 있게 연결해주는 함수
        */
        const { useState } = React; // 객체 구조분해 할당

        function MessageManager() {
            // useState 호출 : [ 상태 값, 상태 변경 함수 ] = useState(상태초기값);
            const [ message, setMessage ] = useState('초기 상태 메세지 입니다.'); // 배열 구조분해 할당
            const [ textColor, setTextColor ] = useState('black');

                    // 상태 변경 함수(Setter)를 호출하면 컴포넌트가 '리렌더링' 된다. (새로고침X)
            // 컴포넌트 함수가 다시 실해오디면서 변경된 state 값으로 JSX 가 다시 만들어진다.
            console.log('MessageManager 컴포넌트가 렌더링 되었습니다.');

            const handleEnter = () => {
                setMessage('안녕하세요! 환영합니다.');
                setTextColor('blue');
            };

            const handleLeave = () => {
                setMessage('안녕히 가세요. 다음에 또 봐요!');
                setTextColor('red');
            };

            return <>
                <h1>함수형 컴포넌트 (useState)</h1>
                <h2 style={{color : textColor}}>{ message }</h2>
                <button onClick={handleEnter}>입장</button>
                <button onClick={handleLeave}>퇴장</button>
            </>;
        }

        function App() {
            return (<>
                <MessageManager />
            </>);
        }

        const root = ReactDOM.createRoot(document.getElementById("root"));
        root.render(<App/>);
    </script>
    ```

#### prev
리액트는 상태 변경을 모아서 처리한다.  
함수형 업데이트 : 이전 상태 값을 안전하게 사용하는 방식. useState 의 setter 함수의 첫 매개변수는 항상 리액트가 관리하는 최신 이전 상태를 가져온다.
```jsx
// useState 를 사용하기 위해 가져옴
const { useState } = React;

function Counter() {
    const [number, setNumber] = useState(0);

    // 함수형 업데이트 : 이전 상태 값을 안전하게 사용하기
    // 같은 이벤트 안에서 이전 state 를 기준으로 연속 계산해야 한다면 이 방식을 사용한다.
    const increaseByTwo = () => {
        // 매개변수를 활용하여 변경. setter 함수의 첫 매개변수는 항상 리액트가 관리하는 최신 이전 상태를 가져온다.
        setNumber((prev) => prev + 1);
        setNumber((prev) => prev + 1);
    };

    return <>
        <h1>함수형 컴포넌트 카운터</h1>
        <h2>현재 숫자 : {number}</h2>
        <button onClick={() => setNumber(number + 1)}>+1</button>
        <button onClick={() => setNumber(number - 1)}>-1</button>
        {/* React는 같은 이벤트 안에서 발생한 상태 변경을 한번에 모아서 처리하기에
            현재 렌더링 시점의 같은 number 값을 기준으로 계산하여 +2 가 아니라 +1 결과가 세팅된다. */}
        <button onClick={() => { setNumber(number + 1); setNumber(number + 1); }}>+2 (의도대로 안됨)</button>
        <button onClick={increaseByTwo}>+2 (함수형 업데이트)</button>
    </>;
}
```

## Event
- onChange : input 안 value 변경 시 이벤트 발생 : `e => setUsername(e.target.value)`

```jsx
const { useState } = React;

function SignupFormBasic() {
    const [username, setUsername] = useState('');
    const [email, setEmail] = useState('');

    const handleSignup = () => {
        alert(`아이디 : ${username}\n이메일 : ${email}\n\n 회원가입 완료!`);
        setUsername('');
        setEmail('');
    };

    return <>
        <h2>기본적인 이벤트 처리</h2>
        <input type="text"
            placeholder="아이디"
            value={username}
            // value 와 onChange 를 함께 연결하면 input 값이 React state 에 의해 관리된다.
            // onChange : input 의 내용물에 변화가 생길 때 마다
            // e.target.value : 이벤트를 일으킨 장본인(e.target)이 가지고 있는 최신 값(value)
            onChange = {e => setUsername(e.target.value)}
        />
        <input type="email"
            placeholder="이메일"
            value={email}
            onChange = {e => setEmail(e.target.value)}
        />
        <button onClick={handleSignup}>가입하기</button>
    </>;
}

function App() {
    return (<>
        <SignupFormBasic/>
    </>);
}
```

### 객체로 state 관리
```jsx
function SignupFormAdvanced() {
    const [form, setForm] = useState({
        username : '',
        email : ''
    });

    // 구조 분해 할당
    const {username, email} = form;

    const handleChange = (e) => {
        // name 은 어떤 input 에서 이벤트가 발생했는지 구분, value 는 사용자가 입력한 최신 값
        const { name, value } = e.target;

        // 기존 form 객체를 스프레드 문법으로 복사
        // 변경이 일어난 input 의 name 을 key로 삼아, 새로운 value 를 덮어쓴다.
        setForm({...form, [name] : value});
    };

    const handleSignup = () => {
        alert(`아이디 : ${username}\n이메일 : ${email}\n\n 회원가입 완료!`);
        setForm({username : '', email : ''});
    };

    return <>
        <h2>효율적인 이벤트 처리</h2>
        <input type="text"
            name="username" // state 객체의 키와 동일한 이름으로 설정
            placeholder="아이디"
            value={username}
            onChange = {handleChange}
        />
        <input type="email"
            name="email"
            placeholder="이메일"
            value={email}
            onChange = {handleChange}
        />
        <button onClick={handleSignup}>가입하기</button>
    </>;
}
```
