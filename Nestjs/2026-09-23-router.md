# Next.js
- React : JS 확장 라이브러리
- Next.js : 리액트에 라우팅 규칙 등 까지 정해진 프레임워크
- Node.js : 개발 도구가 실행될 환경
- npm : 패키지 관리와 프로젝트 명령 실행
- npx : 필요한 도구의 명령 실행
  
## Next.js 프로젝트 생성
Next.js 프로젝트를 생성하고 싶은 위치에서 cmd를 연다
```bash
npx create-next-app@latest 프로젝트명

y > **No, customize settings**
TypeScript ? No
ESLint
React Compiler? No (페이지 기능에 집중하기 위해)
Tailwind CSS? No (미리 정해진 CSS 를 적용하는 기능?)
**src/ directory? Yes
App Router? Yes**
import alias? No (import 할 때 별칭을 지정하겠는가)
AGENTS.md ? No
```

### 실행
프로젝트 폴더
```bash
npm run dev // 작업 시작

Ctrl + c // 작업 끝내기
```
dev 외에 hotfix 나 live 나 그걸 설정 파일 추가해서 설정할 수 있었는데… 연결하는 서버 주소 다르게 해서 proxy 설정할 때 파일이었던가

### 작업 공간
- package.json → dependencies
    - pacakge.json 에 있는 의존성들 설치
    
    ```bash
    npm install
    ```
    
- jsconfig.json
    - src 폴더를 @나 *로 표현한다
    - 그냥 바로 / 부터 경로를 실행하면 public 폴더로 경로 설정 되는듯
    
    ```jsx
    {
      "compilerOptions": {
        "paths": {
          "@/*": ["./src/*"]
        }
      }
    }
    ```
    
- layout.js
    - RootLayout 이 근본이 되고 children 자리에 page.js 에 작성한 것들이 렌더링 된다.
    - adBlock 같은 확장 프로그램으로 인해 처음부터 Hydration Mismatch 에러 발생 > app/layout.js 의 html 태그에 요소 `suppressHydrationWarning` 추가

## 실행 환경
- 서버 컴포넌트 : 서버에서 작성한 정적인 html. 기본적으로 이쪽으로 동작한다.
- 클라이언트 컴포넌트 : 리액트 훅이나 커스텀 훅 들은 클라이언트 컴포넌트에서만 사용할 수 있기에 컴포넌트 상단에 클라이언트 컴포넌트로 사용한다고 명시해야한다. `'use client'`

## 공용 컴포넌트
`src/components` 같이 별개의 폴더를 만들어 재사용할 컴포넌트를 작성  
파일명 예시 : Header.jsx (대문자로 시작, jsx 파일)  
다른 컴포넌트에서 사용하기 위해 마찬가지로 export default 가 필요하다.
- export function : 다른 파일에서 사용 가능
- export default function : 파일에서 기본적으로 사용되는 함수

```javascript
// src/components/Layout.jsx

import Header from "./Header";
import Navbar from "./Navbar";

function Layout({ children }) {
    return <>
        <Header />
        <Navbar />
        { children }
    </>
}

export default Layout;
```
```javascript
// src/app/layout.js (기본적으로 생성 되어 있음)

// jsconfig.json 에서 @ 나 * 을 /src 경로로 설정한다 했기에 경로는 이렇다.
import Layout from "@/components/Layout";

export default function RootLayout({ children }) {
  return (
    <html lang="en" className={`${geistSans.variable} ${geistMono.variable}`}>
      <body>
        <Layout children={children} />
      </body>
    </html>
  );
}
```

### 데이터 사용(json)
```javascript
// MenuAPI.js
import menus from '@/data/menu-detail.json'; 

// 전체 메뉴 데이터 조회
export function getMenuList() {
    return menus;
}

// menuCode 로 메뉴 하나 조회
export function getMenubyMenuCode(menuCode) {
    /** 
	   * 경로 파라미터로 menuCode 를 전달받는다.
     * URL 에서 읽어온 값은 문자열이므로 숫자로 변환해서 비교한다.
     */
    return menus.find(menu => menu.menuCode === Number(menuCode));
}
```

# Router
Next.js 프로젝트에 내장된 라우터 사용  
라우팅 : 주소와 화면을 연결

## next/navigation 이 제공해 주는 hooks
‘use client’ 상단에 선언 필요 : 기본적으로 서버 컴포넌트(사용자와 상호작용 하지 않는 고정된 화면)지만 클라이언트 컴포넌트로 사용할 것이라 명시해주는 것. 서버 컴포넌트가 성능상 좋기에 최대한 필요한 곳에만 선언

- usePathname() : 현재 URL 의 순수 경로를 읽어옴 (활성 탭 / 메뉴 스타일 적용시 사용)
- useParams() : [폴더명] 형태의 동적 라우팅 파라미터를 읽어옴 (상세페이지 `/menu/1` ) (PathVariable)
- useSearchParams() : URL 끝의 쿼리스트링(?key=value)을 읽어옴 (검색 결과, 필터링) (RequestParam)
- useRouter() : 함수/이벤트 내에서 프로그래밍 방식으로 페이지 이동 (폼 제출 후 완료 페이지 이동, 뒤로 가기, 쿼리스트링 있는 url 등 router.push(’url’);)

## 기본 규칙
파일명이 곧 URL 로 매핑된다.  
라우팅을 따로 라우터 태그를 이용해서 꼭 page.js 가 아니게 설정하는 것도 가능하다.

### 정적 경로 매핑

page.js 파일이 실제 페이지 컴포넌트 역할을 한다.

- `app/pages.js` → `/`
- `app/menu/pages.js` → `/menu`

### 동적 경로 매핑

디렉토리 이름을 대괄호로 감싸면 해당 부분이 동적 파라미터가 된다.

- `app/menu/[menuCode]/page.js` → `/menu/1`

## 이동

next/link 모듈에서 가져온 Link 컴포넌트 사용

```jsx
import Link from "next/link";

<Link href={"/about"}>소개 보기</Link>
```

a 태그 : 브라우저가 새 페이지를 요청한다.

Link 태그 : 완전히 새로 가져오는 것이 아니기에 레이아웃 유지 등이 된다.

### usePathname

현재 선택된 경로 찾기

```jsx
'use client'

import { usePathname } from "next/navigation";

const pathname = usePathname(); // /main 같은 현재 페이지 경로가 들어감
```

```jsx
'use client'

import Link from "next/link";
import { usePathname } from "next/navigation";

export default function Navbar() {

    const pathname = usePathname();

    const isActive = (path) => pathname === path;

    const activeStyle = {
        backgroundColor : 'yellow',
        color : 'red'
    };

    return<>
        <p>현재 주소 : {pathname}</p>
        <ul>
            <li><Link href="/" style={isActive("/") ? activeStyle : undefined}>메인</Link></li>
            <li><Link href="/about" style={isActive("/about") ? activeStyle : undefined}>소개</Link></li>
            <li><Link href="/menu" style={isActive("/menu") ? activeStyle : undefined}>메뉴</Link></li>
        </ul>
    </>
}
```

### useParams (PathVariable 방식)

```jsx
// menu/[menuCode]/page.js
'use client'

import { getMenubyMenuCode } from "@/lib/MenuAPI";
import Link from "next/link";
import { useParams } from "next/navigation"
import { useEffect, useState } from "react";

export default function MenuDetail() {
    const { menuCode } = useParams(); // url 의 동적 params 가져오기

    const [menu, setMenu] = useState({});
    
    useEffect(() => {
        setMenu(getMenubyMenuCode(menuCode));
    }, [menuCode]);

    return menu && <>
        <Link href="/menu">뒤로 가기</Link>
        <h1>{menu.menuName} 상세 페이지</h1>
        <h3>메뉴 가격 : {menu.menuPrice}</h3>
        <h3>메뉴 종류 : {menu.categoryName}</h3>
        <h3>메뉴 설명 : {menu.detail?.description}</h3>
        <img src={menu.detail?.image} alt={menu.menuName} style={{maxWidth:500}} />
    </>
}
```

※ useEffect 는 화면을 렌더링하고 실행되니까 useEffect 에서 불러와서 쓰는 값은 이전에는 없이 그려질 수 있다.

### useRouter

next/navigation 에서 import 하는 useRouter

```jsx
// menu/page.js
'use client'

import MenuItem from "@/item/MenuItem";
import { getMenuList } from "@/lib/MenuAPI";
import { useRouter } from "next/navigation";
import { useEffect, useState } from "react";

export default function Menu() {
    const [menuList, setMenuList] = useState([]);
    const [searchValue, setSearchValue] = useState('');

    const router = useRouter();

    useEffect(() => {
        setMenuList(getMenuList());
    }, []);

    const onChangeHandler = (e) => {
        setSearchValue(e.target.value);
    }

    const onClickHandler = () => {
        **router.push**(`/menu/search?menuName=${searchValue}`);
    }

    return <>
        <h1>메뉴 페이지 입니다.</h1>
        <div>
            <input type="search"
                name="menuName"
                value={searchValue}
                onChange={onChangeHandler} />
            <button onClick={onClickHandler}>검색</button>
        </div>
        <div>
            {menuList.map(menu => <MenuItem key={menu.menuCode} menu={menu} />)}
        </div>
    </>
}
```

### useSearchParams (RequestParam 방식)

```jsx
// menu/search/page.js
'use client'

import MenuItem from "@/item/MenuItem";
import { searchMenu } from "@/lib/MenuAPI";
import { useSearchParams } from "next/navigation";
import { useState, useEffect } from "react";

function MenuSearchResultContent() {

    // 쿼리 스트링 객체 가져오기
    const searchParam = useSearchParams();

    // ?menuName=value
    const menuName = searchParam.get('menuName');

    const [menuList, setMenuList] = useState([]);

    useEffect(() => {
        setMenuList(searchMenu(menuName));
    }, [menuName]);

    return <>
        <h1>{menuName} 검색 결과!!!</h1>
        <div>
            {menuList.map(menu => <MenuItem key={menu.menuCode} menu={menu} />)}
        </div>
    </>
}
```

```jsx
// MenuAPI.js

// 메뉴명을 전달받아 메뉴 이름을 포함하고 있는 메뉴 목록 조회
export function searchMenu(searchMenuName) {
    // includes() : 문자열에 검색어가 포함되어 있는지 true/false 로 반환
    return menus.filter(menu => menu.menuName.includes(searchMenuName));
}
```

### Suspense

검색을 기다리는 동안 fallback 속성 안에 있는 화면을 띄울 수 있다.

```jsx
// menu/search/page.js
'use client'

import { Suspense } from "react";

export default function MenuSearchResult() {

    return <>
        <Suspense fallback={<h1>검색 조건을 확인하는 중입니다.</h1>}>
            <MenuSearchResultContent />
        </Suspense>
    </>
}
```
