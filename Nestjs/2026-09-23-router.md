# Next.js
- React : JS 확장 라이브러리
- Next.js : 리액트에 라우팅 규칙 등 까지 정해진 프레임워크
- Node.js : 개발 도구가 실행될 환경
- npm : 패키지 관리와 프로젝트 명령 실행
- npx : 필요한 도구의 명령 실행
  
## Next.js 프로젝트 생성
Next.js 프로젝트를 생성하고 싶은 위치에서 cmd를 연다
```bash
npx create-next-app@latest 프로젝트명

y > **No, customize settings**
TypeScript ? No
ESLint
React Compiler? No (페이지 기능에 집중하기 위해)
Tailwind CSS? No (미리 정해진 CSS 를 적용하는 기능?)
**src/ directory? Yes
App Router? Yes**
import alias? No (import 할 때 별칭을 지정하겠는가)
AGENTS.md ? No
```

### 실행
프로젝트 폴더
```bash
npm run dev // 작업 시작

Ctrl + c // 작업 끝내기
```
dev 외에 hotfix 나 live 나 그걸 설정 파일 추가해서 설정할 수 있었는데… 연결하는 서버 주소 다르게 해서 proxy 설정할 때 파일이었던가

### 작업 공간
- package.json → dependencies
    - pacakge.json 에 있는 의존성들 설치
    
    ```bash
    npm install
    ```
    
- jsconfig.json
    - src 폴더를 @나 *로 표현한다
    - 그냥 바로 / 부터 경로를 실행하면 public 폴더로 경로 설정 되는듯
    
    ```jsx
    {
      "compilerOptions": {
        "paths": {
          "@/*": ["./src/*"]
        }
      }
    }
    ```
    
- layout.js
    - RootLayout 이 근본이 되고 children 자리에 page.js 에 작성한 것들이 렌더링 된다.
    - adBlock 같은 확장 프로그램으로 인해 처음부터 Hydration Mismatch 에러 발생 > app/layout.js 의 html 태그에 요소 `suppressHydrationWarning` 추가

# Router
Next.js 프로젝트에 내장된 라우터 사용  
라우팅 : 주소와 화면을 연결

## next/navigation 이 제공해 주는 hooks
‘use client’ 상단에 선언 필요 : 기본적으로 서버 컴포넌트(사용자와 상호작용 하지 않는 고정된 화면)지만 클라이언트 컴포넌트로 사용할 것이라 명시해주는 것. 서버 컴포넌트가 성능상 좋기에 최대한 필요한 곳에만 선언

- usePathname() : 현재 URL 의 순수 경로를 읽어옴 (활성 탭 / 메뉴 스타일 적용시 사용)
- useParams() : [폴더명] 형태의 동적 라우팅 파라미터를 읽어옴 (상세페이지 `/menu/1` ) (PathVariable)
- useSearchParams() : URL 끝의 쿼리스트링(?key=value)을 읽어옴 (검색 결과, 필터링) (RequestParam)
- useRouter() : 함수/이벤트 내에서 프로그래밍 방식으로 페이지 이동 (폼 제출 후 완료 페이지 이동, 뒤로 가기, 쿼리스트링 있는 url 등 router.push(’url’);)

## 기본 규칙
파일명이 곧 URL 로 매핑된다.  
라우팅을 따로 라우터 태그를 이용해서 꼭 page.js 가 아니게 설정하는 것도 가능하다.

### 정적 경로 매핑

page.js 파일이 실제 페이지 컴포넌트 역할을 한다.

- `app/pages.js` → `/`
- `app/menu/pages.js` → `/menu`

### 동적 경로 매핑

디렉토리 이름을 대괄호로 감싸면 해당 부분이 동적 파라미터가 된다.

- `app/menu/[menuCode]/page.js` → `/menu/1`

## 이동

next/link 모듈에서 가져온 Link 컴포넌트 사용

```jsx
import Link from "next/link";

<Link href={"/about"}>소개 보기</Link>
```

a 태그 : 브라우저가 새 페이지를 요청한다.

Link 태그 : 완전히 새로 가져오는 것이 아니기에 레이아웃 유지 등이 된다.

### usePathname

현재 선택된 경로 찾기

```jsx
'use client'

import { usePathname } from "next/navigation";

const pathname = usePathname(); // /main 같은 현재 페이지 경로가 들어감
```

```jsx
'use client'

import Link from "next/link";
import { usePathname } from "next/navigation";

export default function Navbar() {

    const pathname = usePathname();

    const isActive = (path) => pathname === path;

    const activeStyle = {
        backgroundColor : 'yellow',
        color : 'red'
    };

    return<>
        <p>현재 주소 : {pathname}</p>
        <ul>
            <li><Link href="/" style={isActive("/") ? activeStyle : undefined}>메인</Link></li>
            <li><Link href="/about" style={isActive("/about") ? activeStyle : undefined}>소개</Link></li>
            <li><Link href="/menu" style={isActive("/menu") ? activeStyle : undefined}>메뉴</Link></li>
        </ul>
    </>
}
```
