## 프롬프트 엔지니어링

GPT : Generative Pre-trained Transformer

GPT 의 처리 순서

1. 토큰화(Tokenization) : 문장을 **토크나이저**로 모델이 처리하는 단위인 **토큰**으로 쪼갬
2. 벡터 임베딩 : 벡터 숫자로 바꿈
3. 어텐션 : 문맥 속 중요한 단어에 가중치. 다음 문장에서 사용되는 문장의 연결고리를 계산. (ex. 그) GPT 의 바탕인 **트랜스포머** 구조의 핵심 요소
4. **다음 토큰 예측** : 지금까지의 문맥을 보고 **다음에 올 가능성이 높은 토큰**의 확률을 계산. 이때까지 입력된 문맥을 바탕으로 다음에 이어질 토큰의 확률을 계산하고 토큰(ex. 서울)을 차례로 선택해 문장을 생성
    - 확률을 바탕으로 생성하기에 사실과 다른 내용을 출력할 때도 있다. → 환각(할루시네이션) 현상
5. 구조적 프롬프트 작성

&nbsp;

프롬프트 엔지니어링 순서

1. 질문 입력
2. 보낼 메세지 목록 만들기
3. 답변 받기
4. 화면에 출력
5. 질문과 답을 history 에 저장 → 다음 질문의 2에서 요약해서 함께 넣기 (이전 대화를 기억하지 않기 때문) → 갈수록 이전 대화 내역이 많아 요약이 많이 돼서 이전 대화의 전제가 흐려짐

&nbsp;

### 프롬프트 전송 방식

- input("안내 메세지") : 입력받은 값을 반환
- strip() : 공백 제거
- role : `user`, `system`, `assistant` 등이 들어간다.

```python
import json

# 메세지 목록을 화면에 보여 주고 예시 답변을 돌려준다
def sample_reply(messages):
    print(json.dumps(messages, ensure_ascii=False))
    return "준비된 예시 응답입니다."

# 질문을 받고 답변을 출력하며 대화 이력을 쌓는다
def chat_loop():
    history = []
    system = {"role": "system", "content": "당신은 친절한 강사입니다."}

    while True:
        # input("안내 메세지") : 입력받은 값을 반환
        # strip() : 공백 제거
        question = input("You: ").strip()
        
        # lower() : 소문자로 변환
        if question.lower() in {"exit", "quit", "시스템 종료"}:
            break
        # 파이썬은 조건식에서 빈 문자열을 False 로 취급한다.
        if not question:
            continue

        user = {"role": "user", "content": question}
        # 시스템 지시문 + 히스토리 + 질문 전달
        messages = [system] + history + [user]
        reply = sample_reply(messages)
        print("Bot:", reply)

        # [-10:] : 슬라이싱을 음수로 할 경우 끝에서 10개를 삭제한다는 의미 -> 최근 5개의 대화 이력만 남긴다.
        history = (history + [user, {"role": "assistant", "content": reply}])[-10:]

def main():
    # 들어가는 key 값은 정해져 있다.
    # role 에는 user나 system, assistant 등이 들어간다.
    chat_loop()

if __name__ == "__main__":
    main()
```

### GPT 모델에 실제 요청

`client.chat.completions.create()`

- load_dotenv() : 실행하려는 파일부터 시작해서 상위 폴더로 올라가며 `.env` 파일을 찾아서 그 안의 값을 환경 변수로 읽어온다.
- os.getenv(”env 안 변수명”)
- with : try-with-resources 와 같은 역할. 블록을 벗어나면 자동으로 닫힌다.

```python
import json
import os

from dotenv import load_dotenv # .env 설정 읽기 위해 사용
from openai import APIError, OpenAI # 모델 API 호출

# 질문을 받고 답변을 출력하며 대화 이력을 쌓는다
def chat_loop(reply_to):
    history = []
    system = {"role": "system", "content": "당신은 친절한 강사입니다."}

    while True:
        try:
            # input("안내 메세지") : 입력받은 값을 반환
            # strip() : 공백 제거
            question = input("You: ").strip()
        except (EOFError, KeyboardInterrupt):
            break

        # lower() : 소문자로 변환
        if question.lower() in {"exit", "quit", "시스템 종료"}:
            break
        # 파이썬은 조건식에서 빈 문자열을 False 로 취급한다.
        if not question:
            continue

        user = {"role": "user", "content": question}
        # 시스템 지시문 + 히스토리 + 질문 전달
        messages = [system] + history + [user]
        try:
            reply = reply_to(messages)
        except (APIError, ValueError) as error:
            print("응답 실패", error)
            continue
        print("Bot:", reply)

        # [-10:] : 슬라이싱을 음수로 할 경우 끝에서 10개를 삭제한다는 의미 -> 최근 5개의 대화 이력만 남긴다.
        history = (history + [user, {"role": "assistant", "content": reply}])[-10:]
    
    print("종료합니다.")

# 실제 모델한테 요청해서 응답을 받는다.
def request_reply(client, messages):
    # 실제 요청
    response = client.chat.completions.create(
        model="gpt-4o-mini", # 모델명
        messages=messages,
        max_completion_tokens = 500, # 한 답변에 쓸 수 있는 토큰 수의 상한
        temperature=0.7 # 다음 토큰을 선택할 때 선택의 다양성 (0~2) (수치가 낮으면 일관적이고, 높으면 다양해진다.)
    )

    choice = response.choices[0]
    # content 안에 모델이 응답한 텍스트 값이 들어있다.
    # 파이썬은 단축평가를 지원한다.
    reply = (choice.message.content or "").strip()

    # finish_reason : 모델이 답변 생성을 멈췄을 경우 멈춘 이유 (정상적으로 멈췄으면 "stop" 이 들어있다.)
    if choice.finish_reason != "stop" or not reply:
        raise ValueError("완료된 텍스트 응답을 받지 못했습니다.")
        
    return reply

def main():
    # OPENAI_API_KEY 가 있어야 실제 호출할 수 있다.
    # 실행하려는 파일부터 상위 폴더로 올라가며 .env 를 찾아서 그 안의 값을 환경변수로 읽어온다.
    load_dotenv()
    if not os.getenv("OPENAI_API_KEY"):
        raise ValueError(".env에 OPENAI_API_KEY를 설정하세요.")

    # OpenAI 로 응답을 받는 객체를 만듦
    # OPENAI_API_KEY 란 이름으로 넣어두면 자동으로 키를 읽어온다.
    with OpenAI(timeout=20.0, max_retries=0) as client:
        def live_reply(messages):
            return request_reply(client, messages)

        chat_loop(live_reply)

if __name__ == "__main__":
    main()
```
