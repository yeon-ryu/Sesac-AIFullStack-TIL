# Timer
## 동기 프로그래밍 (Blocking)
앞선 작업이 끝날 때까지 다음 작업이 기다리는 방식  
기다리는 동안 페이지 전체가 막혀서 아무런 반응도 안 한다.
```html
<button id="sync-btn">동기 작업 시작 (3초 멈춤!)</button>
<button id="test-btn">반응 테스트</button>
<script>
    function sleep(delay) {
        const delayUntil = Date.now() + delay;
        while(Date.now() < delayUntil);
    }

    document.getElementById('sync-btn').addEventListener('click', e => {
        console.log('동기 작업 시작');
        sleep(3000); // 3초
        console.log('동기 작업 완료');
    });
</script>
```

## 비동기 프로그래밍 (Asynchronous)
나중에 할 일을 브라우저에게 맡겨두고, 자신은 즉시 다음 코드를 실행
- setTimeout(콜백함수, 기다릴 시간 ms, ...콜백함수에 들어가는 매개변수);
    ```html
    <h4>setTimeout: "조금 이따가, 딱 한 번만 해줘!"</h4>
    <script>
        // 3초 뒤에 콜백 함수 실행
        // setTimeout(콜백함수, 기다릴 시간 ms, ...콜백함수에 들어가는 매개변수);
        const timerId = setTimeout((name) => {
            console.log(name, "3초가 지났습니다.");
        }, 3000, "강사님");
    
        console.log('타이머는 예약되었습니다.'); // setTimeout 을 기다리지 않고 바로 실행
    
        // 타이머 취소
        clearTimeout(timerId);
        console.log('타이머가 취소되었습니다.');
    </script>
    ```

- setInterval(콜백함수, 반복 주기 ms, ...콜백함수에 들어가는 매개변수);
    ```html
    <h4>setInterval: "계속 반복해서 해줘!" (feat. clearInterval)</h4>
    <script>
        let count = 1;
    
        // 1초마다 콜백 함수 반복
        // intervalId(콜백함수, 반복 주기 ms, ...콜백함수에 들어가는 매개변수);
        const intervalId = setInterval(() => {
            console.log(`${count}초`);
    
            if(count++ >= 5) {
                clearInterval(intervalId);
                console.log("setInterval 반복이 중지되었습니다.");
            }
        }, 1000);
    </script>
    ```

### 비동기 동작 원리
1. **Call stack** : JavaScript 엔진이 지금 실행 중인 작업 공간
2. **Web API** : 브라우저가 제공하는 API(함수들이 있는 공간). 브라우저나 Node.js 가 제공하는 타이머, 이벤트, 네트워크 처리 공간
3. **Task Queue** : 비동기 작업이 끝난 뒤 실행 대기 중인 콜백들이 줄 서는 공간
4. **Event Loop** : Call Stack 이 비었는지 확인하고, Task Queue 의 콜백을 다시 Stack 으로 올려주는 관리자
```html
<script>
    console.log('Event Loop : 시작!'); // 1번째 실행

    // 타이머를 0 으로 설정하더라도 setTimeout 함수는 Web API > Task Queue > Call Stack 으로 이동되기에 현재 코드가 다 수행되고 실행된다.
    setTimeout(() => {
        console.log('Event Loop : 타이머 완료! (Task Queue)');
    }, 0); // 3번째 실행

    console.log('Event Loop : 끝!'); // 2번째 실행
</script>
```
Web API (브라우저) > Task Queue > Call Stack (JavaScript 작업 공간)

# BOM
브라우저 제어
- DOM : HTML 문서의 태그, 텍스트, 속성을 다루는 객체 모델
- BOM : 브라우저 창, 주소창, 방문 기록, 화면 정보처럼 브라우저 환경 자체를 다루는 객체 모델  

window 는 전역 개체라 보통 생략하고 사용한다. (document == window.document, alert() == window.alert())

## 사용자 반응
- alert : 간단한 알림창 (확인 버튼만 있음)
- confirm : 확인/취소 질문을 하는 알림창. boolena 값 반환
- prompt : 사용자에게 텍스트를 입력받는 알림창. 확인을 누르면 입력한 문자열이 반환되고, 취소를 누르면 null 이 반환된다.
```html
<button id="confirmBtn">진행 여부 묻기</button>
<button id="promptBtn">이름 입력받기</button>
<p id="message"></p>
<script>
    // alert : 간단한 알림창 (확인 버튼만 있음)
    // alert('페이지 로딩 완료!');

    const $confirmBtn = document.getElementById('confirmBtn');
    const $promptBtn = document.getElementById('promptBtn');
    const $message = document.getElementById('message');

    // confirm : 확인/취소 질문을 하는 알림창. boolena 값 반환
    $confirmBtn.addEventListener('click', () => {
        const answer = confirm('결제를 진행하시겠습니까?');
        if(answer) {
            $message.textContent = '결제를 진행합니다.';
        } else {
            $message.textContent = "결제가 취소되었습니다.";
        }
    });

    // prompt : 사용자에게 텍스트를 입력받는 알림창. 확인을 누르면 입력한 문자열이 반환되고, 취소를 누르면 null 이 반환된다.
    // 빈칸으로 확인을 누르면 빈 문자열('')이 반환되므로 trim()으로 공백 검사를 한다.
    $promptBtn.addEventListener('click', () => {
        const name = prompt('당신의 이름은 무엇인가요?');

        if(name) {
            $message.textContent = `반갑습니다 ${name}님!`;
        } else {
            $message.textContent = `이름이 입력되지 않았습니다.`;
        }
    });
</script>
```

## 페이지 제어
- location.href : URL을 할당하면 해당 페이지로 이동. 브라우저 방문 기록에 남는다. (=이전 버튼을 눌러서 이전 페이지로 돌아올 수 있음)
- location.replace() : 현재 페이지를 새 페이지로 대체하여 방문 기록이 남지 않는다. (=이전 버튼으로 해당 이전 페이지로 돌아올 수 없음). 로그인 화면 등에 사용
- location.reload() : 현재 페이지를 새로고침한다. 서버에서 다시 데이터를 받아 화면을 초기 상태로 되돌리고 싶을 때 사용할 수 있다.
```html
<button id="moveBtn">구글로 이동</button>
<button id="replaceBtn">네이버로 이동 (뒤로가기 불가)</button>
<button id="reloadBtn">새로고침</button>
<script>
    document.getElementById('moveBtn').addEventListener('click', () => {
        // location.href 에 URL을 할당하면 해당 페이지로 이동
        // 브라우저 방문 기록에 남는다. (=이전 버튼을 눌러서 이전 페이지로 돌아올 수 있음)
        location.href = "https://www.google.com";
    });

    document.getElementById('replaceBtn').addEventListener('click', () => {
        // location.replace() : 현재 페이지를 새 페이지로 대체하여 방문 기록이 남지 않는다. (=이전 버튼으로 해당 이전 페이지로 돌아올 수 없음)
        // 로그인 화면 등에 사용.
        location.replace("https://www.naver.com");
    });

    document.getElementById('reloadBtn').addEventListener('click', () => {
        // location.reload() : 현재 페이지를 새로고침한다.
        // 서버에서 다시 데이터를 받아 화면을 초기 상태로 되돌리고 싶을 때 사용할 수 있다.
        location.reload();
    });
</script>
```

## 방문 기록 제어
history 객체로 뒤로가기, 앞으로가기 동작 가능  
브라우저 보안 정책상 실제 방문 기록 url 목록을 읽을 수는 없다.
```html
<button onclick="history.back()">뒤로 가기</button>
<button onclick="history.forward()">앞으로 가기</button>
<button onclick="history.go(-2)">2페이지 뒤로 가기</button>
```
