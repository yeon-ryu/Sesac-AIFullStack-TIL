# Event
## 이벤트 핸들러 / 이벤트 리스너
이벤트가 발생했을 때 실행할 함수
- 구식 방식
    HTML 안에 JavaScript 코드가 섞여서 유지보수가 어렵다. (권장되지 않는다.)
    
    ```html
    <button onclick="alert('첫 번째 버튼 클릭!');">방법 1 버튼</button>
    ```
    
- 과도기 방식
    HTML 과 JaavaScript 를 분리했지만, 하나의 이벤트에 오직 하나의 임무만 부여할 수 있다.
    ```html
    <button id="btn2">방법 2 버튼</button>
    <script>
        const $btn2 = document.getElementById("btn2");
        $btn2.onclick = function() {
            alert('첫 번째 임무 수행');
        };
        // onclick 프로퍼티에는 함수 하나만 저장할 수 있는 변수 같은 공간이기 때문에 나중에 대입한 함수가 이전 함수를 대체한다.
        $btn2.onclick = function() {
            console.log('두 번째 임무 수행');
        };
    </script>
    ```
    
- **현대 표준 방식 (addEventListener)**
    요소.addEventListener('이벤트종류', 실행할함수); 형태로 사용한다.
    
    ```html
    <button id="btn3">방법 3 버튼</button>
    <script>
        const $btn3 = document.getElementById("btn3");
        
        // 요소.addEventListener('이벤트종류', 실행할함수)
        // 전부 실행된다.
        $btn3.addEventListener('click', function() {
            console.log('버튼3 첫 번째 임무 수행');
        });
        $btn3.addEventListener('click', () => {
            alert('버튼3 두 번째 임무 수행');
        });
    </script>
    ```

### 이벤트 핸들러 추가/제거
이벤트를 제거할 때, 제거할 함수는 반드시 이름이 있거나 변수에 담겨 있어야 한다.
```html
<button id="btn4">추가/제거 버튼</button>
<button id="addBtn">임무 추가</button>
<button id="removeBtn">임무 제거</button>

<script>
    const $btn4 = document.getElementById('btn4');
    const $addBtn = document.getElementById('addBtn');
    const $removeBtn = document.getElementById('removeBtn');

    // 나중에 제거해야 하는 핸들러는 반드시 함수의 참조를 보관한다.(표현식)
    const mission = () => {
        alert('특수 임무 수행 완료');
    };

    // 버튼 클릭시 mission 임무를 btn4 에 추가한다.
    $addBtn.addEventListener('click', () => {
        $btn4.addEventListener('click', mission);
        console.log('btn4 에 임무가 추가되었습니다.');
    });

    // 버튼 클릭시 mission 임무를 btn4 에 제거한다.
    $removeBtn.addEventListener('click', () => {
        $btn4.removeEventListener('click', mission);
        console.log('btn4 의 임무가 제거되었습니다.');
    })

    // 익명함수는 제거할 수 없다. 위의 함수와 다른 함수로 취급된다.
    // $btn4.addEventListener('click', () => { alert('임무'); });
    // $btn4.removeEventListener('click', () => { alert('임무'); });
</script>
```

## 이벤트 객체와 this
### 이벤트 객체
이벤트가 발생하면, 브라우저는 이벤트 객체를 생성하고 해당 객체는 이벤트 핸들러의 첫번째 인자로 자동 전달 된다.
```html
<h2 id="msg">여기를 클릭하면, 클릭한 곳의 마우스 좌표를 알려드립니다.</h2>

<script>
    const $msg = document.getElementById('msg');
    // 이벤트 핸들러의 첫번째 매개변수로 받는 것은 이벤트의 정보를 담고 있는 '이벤트 객체' 이다.
    document.addEventListener('click', (event) => {
        console.log(event);

        // 클릭한 마우스 좌표 (clientX, clientY)
        $msg.textContent = `마우스 좌표 -> X : ${event.clientX}, Y : ${event.clientY}`;
        
        console.log('실제 클릭 대상(e.target) :', event.target); // <h3>2. 핸들러 내부의 `this`: '사건 당사자'는 누구인가?</h3>
    });
</script>
```
event 객체의 target 프로퍼티 : 클릭한 요소

### this
- 일반 function 함수 사용 시 this : 이벤트 핸들러가 등록된 요소. e.currentTarget 과 같은 값.
    ```html
    <button id="btn">클릭해보세요</button>
    
    <script>
        const $btn = document.getElementById('btn');
        
        $btn.addEventListener('click', function(e) {
            console.log('this :', this); // 이벤트 핸들러가 등록된 요소 // <button id="btn">클릭해보세요</button>
    
            console.log('e.currentTarget :', e.currentTarget); // 이벤트 핸들러가 등록된 요소
            console.log(this === e.currentTarget); // true
    
            this.style.backgroundColor = 'green';
        });
    </script>
    ```
    
- 화살표 함수 사용 시 this : 바깥 스코프의 this.
    ```html
    <button id="btn">클릭해보세요</button>
    
    <script>
        const $btn = document.getElementById('btn');
        
        $btn.addEventListener('mouseover', (e) => {
            console.log('this :', this); // 화살표 함수가 작성된 바깥 스코프의 this 를 사용 // Window 객체
    
            console.log('e.currentTarget :', e.currentTarget); // 이벤트 핸들러가 등록된 요소 // <button id="btn">클릭해보세요</button>
        });
    </script>
    ```
    
- 이벤트객체.currentTarget : 실행 중인 이벤트 핸들러가 등록된 요소.
    ```html
    <button id="best-practice-btn">Best Practice</button>
    <script>
        const $bestBtn = document.getElementById("best-practice-btn");
    
        $bestBtn.addEventListener('click', (e) => {
            // e.currentTarget 이 나중에 바뀔 수 있기에 별도의 변수에 저장해서 사용
            const btn = e.currentTarget;
    
            btn.textContent = '클릭되었습니다!';
            btn.style.backgroundColor = 'skyblue';
    
            // setTimeout(실행할 함수, 대기 시간)
            // 2 초 후 스타일 적용했던거 리셋
            setTimeout(() => {
                btn.textContent = 'Best Parctice';
                btn.style.backgroundColor = '';
            }, 2000);
        });
    </script>
    ```
**결론 : 현재 요소를 선택할 때는 this 대신 e.currentTarget 을 사용하자!**

### 이벤트 전파와 위임
- e.target : 이벤트가 실제로 시작된 요소
- e.currnetTarget : 현재 이벤트 핸들러가 등록된 요소

이벤트 전파 단계
1. 캡처링 : window 에서 이벤트 발생 요소 방향으로 내려감
2. 타킷 단계 : 실제 이벤트 대상에 도착
3. 버블링 단계 : 실제 이벤트 대상에서 부모 방향으로 올라감

### 이벤트 버블링 (전파)
자식에서 발생한 이벤트가 부모한테 버블링 되어 부모의 이벤트 핸들러도 실행된다.
```html
<ul id="parent"> 부모 (ul)
    <li id="child"> 자식 (li) </li>
</ul>

<script>
    const $parent = document.getElementById('parent');
    const $child = document.getElementById('child');

    $parent.addEventListener('click', (e) => {
        alert('부모(ul)가 클릭을 감지했습니다.');
        console.log('e.target :', e.target); // 이벤트가 실제로 시작된 요소 // 자식을 클릭 시 자식 요소가 출력된다.
        console.log('e.currentTarget :', e.currentTarget); // 이벤트 핸들러가 등록된 요소 // 자식을 클릭하더라도 부모 요소가 출력된다.
    });

    $child.addEventListener('click', (e) => {
        alert('자식(li)가 클릭을 감지했습니다.'); // li 를 클릭하면 li 이벤트가 먼저 발생하고 부모인 ul 이벤트도 발생한다.
    });
</script>
```

### 이벤트 위임
부모 요소에 이벤트 핸들러를 단 하나만 등록하여 모든 자식의 이벤트를 처리할 수 있다.
나중에 동적으로 추가되는 자식요소에도 이벤트 핸들러가 자동으로 동작한다.
```html
<ul id="drink-list">
    <li>커피</li>
    <li>콜라</li>
    <li>우유</li>
</ul>
<button id="add-btn">음료 추가</button>

<script>
    /*
    // 개별로 하나씩 이벤트 핸들러 등록하는 방식
    const $items = document.querySelectorAll('#drink-list li');
    $items.forEach(($item) => {
        $item.addEventListener('click', () => {
            $item.classList.toggle('highlight');
        });
    });
    */

    // 이벤트 위임 활용
    const $drinkList = document.getElementById('drink-list');
    const $addBtn = document.getElementById('add-btn');
    
    function highlight(element) {
        element.classList.toggle('highlight');
    }

    $drinkList.addEventListener('click', e => {
        // e.target 이 자식(li)일 경우만 실행 되도록 안전 장치
        if(e.target.matches('li')) {
            highlight(e.target); // e.target : 자식을 클릭할 시 자식 요소
        }
    });
    
    // 장점 : 나중에 동적으로 추가되는 자식요소에도 이벤트 핸들러가 자동으로 동작한다.
    $addBtn.addEventListener('click', () => {
        const $newLi = document.createElement("li");
        $newLi.textContent = '사이다';
        $drinkList.appendChild($newLi);
    });
</script>
```

```html
<ul id="drink-list">
    <li><strong>커피</strong></li>
    <li>콜라</li>
    <li>우유</li>
</ul>

<script>
    $drinkList.addEventListener('click', e => {
        // 만약 li 안에 strong 같은 태그가 들어갔을 경우 strong 태그 선택시에 실행이 안될 수 있다.
        // closest : 가장 가까운 전달된 요소(li) 를 찾는다. 나부터 확인하여 차례대로 부모까지 확인.
        const $item = e.target.closest("li"); // 찾지 못할 경우 null 을 반환

        if(!$item) return;
        if(!$drinkList.contains($item)) return;

        highlight($item);
    });
</script>
```
- 요소.matches(’태그’) : 해당 태그와 일치하는지 확인 (true / false)
- 요소.closest(’태그’) : 자기 자신부터 시작하여 가장 가까운 전달된 요소를 찾는다. 못 찾을 경우 null (Falsy한 값) 을 반환

## 이벤트 제어
### preventDefault (브라우저 동작)
브라우저의 기본 동작을 막는 기능
```html
<form id="login-form">
    <div class="form-group">
        <label for="username">아이디:</label>
        <input type="text" id="username">
    </div>
    <button type="submit">로그인</button>
    <p class="error-message"></p>
</form>

<script>
    const $loginForm = document.getElementById('login-form');
    const $usernameInput = document.getElementById('username');
    const $errorMessage = document.querySelector('.error-message');

    $loginForm.addEventListener('submit', (e) => {
        // submit 은 기본적으로 브라우저가 action 주소로 이동하거나 페이지를 새로고침한다.
        // 유효성 검사를 위해 자동 새로고침 기본 동작을 멈춘다.
        e.preventDefault();

        // 유효성 검사 수행
        if($usernameInput.value.trim().length <= 0) {
            $errorMessage.textContent = '아이디를 입력해주세요.';
            $usernameInput.value = '';
        } else if($usernameInput.value.includes(' ')) {
            $errorMessage.textContent = '아이디에 공백은 입력할 수 없습니다.';
        } else {
            $errorMessage.textContent = '';
            console.log("서버로 제출할 아이디 :", $usernameInput.value);
            alert("로그인 성공!");
        }
    });
</script>
```

- 마우스 우클릭 막기
    ```javascript
    // 마우스 우클릭 막기 (contextmenu : 우클릭시 열리는 메뉴)
    $usernameInput.addEventListener('contextmenu', (e) => {
        e.preventDefault();
    });
    ```

### stopPropagation (이벤트 버블링)
이벤트 전파(버블링) 막는 기능
```html
<div id="modal-background" class="modal-background">
    <div id="modal-content" class="modal-content">
        <h3>모달 창</h3>
        <p>이 흰색 영역을 클릭해도 모달은 닫히지 않아야 합니다.</p>
        <p>하지만 바깥 회색 영역을 클릭하면 닫힙니다.</p>
    </div>
</div>

<script>
    const $modalBg = document.getElementById('modal-background');
    const $modalContent = document.getElementById('modal-content');

    $modalBg.addEventListener('click', (e) => {
        console.log('회색 배경(부모) 클릭 -> 모달을 닫습니다.');
        
        // if(!e.target.closest('.modal-content')) {
            // 모달 배경 display : none 으로 변경
            $modalBg.style.display = 'none';
        // }
    });

    $modalContent.addEventListener('click', (e) => {
        // modal-content 에서 버블링을 막아서 부모인 modal-background 까지 올라가지 않는다.
        e.stopPropagation();
        console.log('흰색 내용(자식) 클릭 -> 버블링을 막았습니다.');
    });
</script>
```

## 마우스 키보드 이벤트
### 마우스
- click (클릭) : 왼쪽 버튼 눌렀다 뗐을 때
- dblclick (더블 클릭) : 왼쪽 버튼 더블 클릭
- mousedown (누를 때) : 모든 버튼 누르는 순간
- mouseup (뗄 때) : 모든 버튼 떼는 순간
- mousemove (움직일 때)
- contextmenu (마우스 우클릭)
- mouseover (마우스 올렸을 때)
- event.button -> 0 : 왼쪽, 1 : 가운데(휠), 2 : 오른쪽
```html
<script>
    $mouseBtn.addEventListener('mousedown', e => {
		    // e.button -> 0 : 왼쪽, 1 : 가운데(휠), 2 : 오른쪽
        $mouseArea.innerHTML += `mousedown 이벤트 발생! ${e.button}<br>`;
    });
</script>
```

### 키보드
- keydown: 키를 누르는 순간 (누르고 있는 동안 계속 발생)
- keyup: 키에서 손을 떼는 순간
- event.key: 입력된 문자를 알려줌 (ex: 'a', 'A', 'Enter')
- event.code: 실제 물리적인 키 코드를 알려줌 (ex: 'KeyA', 'Enter')
```html
<input type="text" id="keyboard-input" placeholder="아무 키나 입력하세요">
<div id="keyboard-area" class="area"></div>
<script>
    const $keyboardInput = document.getElementById("keyboard-input");
    const $keyboardArea = document.getElementById("keyboard-area");

    $keyboardInput.addEventListener('keydown', e => {
        $keyboardArea.textContent = `keydown 이벤트 발생!
        e.key : ${e.key}
        e.code : ${e.code}`;
        
        if(e.key === 'Enter') {
            console.log('검색을 실행합니다.');
            // 실제 검색 함수 호출
        }
    });
</script>
```

## 폼 이벤트
- 폼 선택 : document.forms.폼name속성값; document.forms[’form 태그 name 속성 값’];
- input 선택 : $form.인풋name속성값; 폼에 포함된 입력 요소는 name 속성 값으로 가져 올 수 있다.
```html
<form name="joinForm" action="https://example.com/join" method="GET">
    <div class="form-group">
        <label for="username">이름</label>
        <input type="text" name="username" id="username" value="홍길동">
    </div>

    <div class="form-group">
        <label>관심사 (2개 이상 선택)</label><br>
        <input type="checkbox" name="hobby" value="exercise" checked> 운동
        <input type="checkbox" name="hobby" value="music"> 음악
        <input type="checkbox" name="hobby" value="movie"> 영화
    </div>

    <div class="form-group">
        <label for="introduce">자기소개 (<span id="char-counter">0</span>/100자)</label>
```
